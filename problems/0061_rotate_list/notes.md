# 61. Rotate List

- 链接: https://leetcode.com/problems/rotate-list/
- 难度: Medium
- 最优解: 241225.py

## 题型
链表

## 识别信号
- 链表整体向右旋转 k 位，等价于把末尾 k 个节点整体搬到头部
- k 可能远大于链表长度（k ≤ 2·10^9）

## 解题步骤
记 n = 链表长度。
1. 暴力：每次把尾节点摘下来接到头部，重复 k 次，O(n·k)，k 可达 2·10^9 必然超时
2. 瓶颈：旋转 n 次等于没转，有效的旋转次数只有 k % n
3. 优化：一遍遍历求出 n 并拿到尾节点；把尾节点接到头节点成环；从头走到第 n − k % n 个节点，它的 next 是新头，在这里断开，O(n) 时间、O(1) 空间

## 关键一步
先 k %= n，新头是第 n − k 个节点的下一个节点：首尾相连成环后，在第 n − k 个节点处断开。

## 易错点
- 空链表或只有一个节点时直接返回，否则后面会访问空节点：原注释 "Notice: remember to check input range"
- k 是 n 的倍数时 target = n，在尾节点处断开，结果等于原链表
- 第二次遍历时别忘了移动指针：原注释 "Notice: Do not forget transfer current"
