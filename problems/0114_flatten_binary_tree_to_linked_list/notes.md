# 114. Flatten Binary Tree to Linked List

- 链接: https://leetcode.com/problems/flatten-binary-tree-to-linked-list/
- 难度: Medium
- 最优解:

## 题型
二叉树 · DFS

## 识别信号
- 展开后的节点顺序就是前序遍历的顺序
- 要求原地修改（函数返回 None），进阶要求 O(1) 额外空间

## 解题步骤
记 n = 节点数，h = 树高。
1. 暴力：前序遍历把节点存进列表，再依次把每个节点的 left 置空、right 指向列表里的下一个，O(n) 时间、O(n) 空间
2. 瓶颈：要额外存 n 个节点
3. 优化一：按 右 → 左 → 根 的顺序递归（前序的逆序），用变量 prev 记住上一个处理完的节点，把当前节点的 right 指向 prev、left 置空，再把 prev 更新为当前节点，O(n) 时间、O(h) 栈空间
4. 优化二：从根开始迭代，若当前节点有左子树，找到左子树里最右边的节点，把当前节点原来的右子树接到它的 right 上，再把左子树整体移到 right、left 置空；然后沿 right 走到下一个节点。找最右节点走过的路径加起来是 O(n)，总 O(n) 时间、O(1) 空间

## 关键一步
前序里，右子树紧跟在左子树的最后一个节点（左子树最右边的节点）之后，所以把右子树接到这个节点的 right 上，再把左子树整体挪到右边，就完成了当前节点的展开。

## 易错点
- 每个节点的 left 都要置为 None，否则结果里左孩子还在
- 函数返回 None，要修改的是传入的 root 本身，不要新建节点
- 改 right 之前先保存原来的右子树，否则会丢掉它
- 按前序递归时如果先改了 root.right，再去递归"原右子树"拿到的已经是改过的指针
