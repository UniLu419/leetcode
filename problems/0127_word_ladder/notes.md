# 127. Word Ladder

- 链接: https://leetcode.com/problems/word-ladder/
- 难度: Hard
- 最优解:

## 题型
BFS · 哈希表

## 识别信号
- 每次只能改一个字母，中间词必须在 wordList 里 → 隐式图，边是"只差一个字母"
- 求最短转换序列的长度 → 无权图上的最短路
- wordList 可达 5000，两两比较建图会超时，需要更快地找邻居

## 解题步骤
记 N = len(wordList)，L = 单词长度，字母表大小为 26。
1. 暴力：两两比较单词建邻接表 O(N²·L)，再 BFS；N = 5000 时约 10^8 次字符比较，超时
2. 瓶颈：绝大多数词对都不相邻，比较几乎全是浪费
3. 优化一：不建图，BFS 时现生成邻居——把当前词每一位换成 26 个字母，查哈希集合是否存在；每个词 26·L 个候选、每个拼接 O(L)，总 O(N·26·L²)
4. 优化二：双向 BFS，从 beginWord 和 endWord 两头同时扩展，每次扩展当前较小的一侧，两侧相遇即得答案；最坏复杂度不变，但搜索的节点数大幅减少

## 关键一步
不预先建图：BFS 中对当前词逐位替换 26 个字母来生成邻居并查集合，访问过的词立刻从集合里删掉；层数就是序列长度。

## 易错点
- 答案是序列中的单词个数（含 beginWord），等于边数 + 1
- endWord 不在 wordList 里直接返回 0
- beginWord 可以不在 wordList 里
- 访问过的词要在入队时就删除或标记，否则同一层会重复入队，复杂度失控
- 双向 BFS 每次扩展较小的一侧，并在生成邻居时就检查是否已在另一侧
