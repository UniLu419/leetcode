# 124. Binary Tree Maximum Path Sum

- 链接: https://leetcode.com/problems/binary-tree-maximum-path-sum/
- 难度: Hard
- 最优解:

## 题型
二叉树 · DFS · 动态规划

## 识别信号
- 路径可以从任意节点开始、在任意节点结束，不一定经过根，求最大路径和
- 节点值可以为负
- 任何一条路径都有一个最高的节点，路径从那里向左、向右各往下延伸一段（也可以不延伸）

## 解题步骤
记 n = 节点数，h = 树高。
1. 暴力：枚举每个节点作为路径的最高点，分别递归求它左孩子、右孩子往下的最大单链和，取正的部分加上该节点；每个节点都重新递归一遍子树，O(n·h)，退化成链时 O(n²)
2. 瓶颈：同一棵子树往下的最大单链和被重复计算
3. 优化：一次后序 DFS，函数返回"从该节点出发只往下走一侧的最大单链和" gain = node.val + max(0, 左孩子的 gain, 右孩子的 gain)；同时在每个节点用 node.val + max(0, 左 gain) + max(0, 右 gain) 更新全局答案。O(n) 时间、O(h) 栈空间

## 关键一步
函数返回给父节点的值只能是一侧的单链（父节点还要接上它），而全局答案是在当前节点拐弯、左右两侧都可以取；负的单链贡献直接当作 0 不要。

## 易错点
- 全局答案初始值要用负无穷（或根的值），不能用 0：全是负数时答案是最大的那个负数（[-2, -1] → -1）
- 返回给父节点的值不能把左右两侧都加上
- 子链和为负时取 0 表示不延伸，但当前节点本身一定要选
- 答案不一定经过根（[-10, 5, 6] → 6）
