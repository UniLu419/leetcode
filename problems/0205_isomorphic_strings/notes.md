# 205. Isomorphic Strings

- 链接: https://leetcode.com/problems/isomorphic-strings/
- 难度: Easy
- 最优解: 241218.py

## 题型
哈希表

## 识别信号
- 两个字符串逐位置对应，判断能否在字符之间建立映射
- "不同字符不能映射到同一个字符"，说明映射必须是一一对应

## 解题步骤
记 n = len(s)。
1. 暴力：对每个位置 i，检查所有 j < i 是否满足"s[i] == s[j] 当且仅当 t[i] == t[j]"，O(n²)
2. 瓶颈：反复和前面所有位置比较；其实只需要知道每个字符之前被映射成了什么
3. 优化：两个哈希表分别记录 s → t 和 t → s 的映射，一遍扫描，遇到冲突就返回 False，O(n)

## 关键一步
只记 s → t 不够，还要记 t → s：s 里一个新字符想映射到的 t 字符如果已经被别的字符占用，就不同构（"badc" 和 "baba"）。

## 易错点
- 原注释：注意这里要求不同字母不可以映射到同一个字母上，所以需要双向hash
- 反例 "badc" / "baba"：只做 s → t 单向检查会误判为 True
