# 149. Max Points on a Line

- 链接: https://leetcode.com/problems/max-points-on-a-line/
- 难度: Hard
- 最优解:

## 题型
哈希表 · 数学

## 识别信号
- 求最多有多少个点在同一条直线上，n ≤ 300，O(n²) 可行、O(n³) 偏慢
- 经过一个固定点的直线由斜率唯一确定，可以按斜率分组计数

## 解题步骤
记 n = len(points)。
1. 暴力：枚举两个点确定一条直线，再检查其余每个点是否在线上（叉积为 0），O(n³)
2. 瓶颈：同一条直线被不同的点对反复确定、反复检查
3. 优化：固定点 i，用哈希表统计其余每个点 j 相对 i 的斜率出现次数，斜率相同的点与 i 共线，出现最多的次数 + 1 就是过 i 的最多共线点数，O(n²) 时间、O(n) 空间
4. 斜率的表示：用 dx = xj - xi、dy = yj - yi 同除以 gcd(dx, dy) 后的元组 (dx, dy)，并统一符号（dx < 0 时两者同时取反，dx == 0 时令 dy > 0），避免浮点误差和除以 0

## 关键一步
固定一个点之后，"和它共线"等价于"相对它的斜率相同"，问题就变成用哈希表找出现次数最多的斜率。

## 易错点
- 竖直线 dx = 0，直接用 dy / dx 会除以 0
- 约分后要统一符号，否则 (1, 2) 和 (-1, -2) 会被当成两种斜率
- 只有一个点时答案是 1，不是 0
- 每换一个固定点 i，哈希表要重新开始计数
- 题目保证点互不相同，不需要处理重合点
