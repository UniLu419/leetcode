# 52. N-Queens II

- 链接: https://leetcode.com/problems/n-queens-ii/
- 难度: Hard
- 最优解:

## 题型
回溯 · 位运算

## 识别信号
- n×n 棋盘放 n 个互不攻击的皇后、求方案数 → 每行恰好一个皇后，可以逐行搜索
- 冲突只来自同列、同主对角线、同副对角线三类，可以随搜索维护

## 解题步骤
记 n 为棋盘边长（≤ 9）。
1. 暴力：枚举每行皇后所在的列（n^n 种），或只枚举列的全排列（n! 种），放完再检查对角线，O(n!·n)
2. 瓶颈：冲突要到放完才发现，前几行就已冲突的分支仍被完整展开
3. 回溯：逐行放置，每放一个就检查列、主对角线（行 − 列 相同）、副对角线（行 + 列 相同），冲突就不往下走；用三个集合记录已占用的列和两类对角线，判断 O(1)，搜索规模约 O(n!)
4. 位运算：用三个整数的二进制位表示被占用的列和两类对角线；进入下一行时两个对角线掩码分别左移、右移一位，可放的位置是全 1 掩码 (1 << n) − 1 里三者都为 0 的位，每次用 avail & −avail 取出最低位；复杂度不变，常数最小

## 关键一步
每行只放一个皇后，用"列""行 − 列""行 + 列"三类占用标记在 O(1) 内判断冲突，冲突的分支在当行就剪掉。

## 易错点
- 两类对角线的不变量不同：主对角线是 行 − 列 不变（可能为负，用集合或加 n − 1 偏移），副对角线是 行 + 列 不变
- 回溯时三类标记都要撤销
- n = 2 和 n = 3 无解，返回 0；n = 1 返回 1
- 位运算写法中对角线掩码移位后要和 (1 << n) − 1 取与，去掉移出棋盘的位
