# 199. Binary Tree Right Side View

- 链接: https://leetcode.com/problems/binary-tree-right-side-view/
- 难度: Medium
- 最优解:

## 题型
二叉树 · BFS · DFS

## 识别信号
- 从右边看，每一层只能看到最右边的一个节点，答案就是"每层的最后一个节点"
- 输出按从上到下的层排列，层数就是答案长度

## 解题步骤
记 n = 节点数，h = 树高，w = 最宽一层的节点数。
1. 直觉做法（错误）：只沿右孩子一路往下走，O(h)；但左子树更深时，左子树下层的节点也能从右边看到（例 2 的 4、5 都来自左子树）
2. 暴力：先做完整的层序遍历，保存每层的全部节点，再取每层最后一个，O(n) 时间、O(n) 空间
3. 优化一：BFS 按层处理，不保存整层，只记下每层最后出队的节点值，O(n) 时间、O(w) 空间
4. 优化二：DFS 先右后左并带上深度，某个深度第一次被访问到的节点就是该层最右的节点，O(n) 时间、O(h) 空间

## 关键一步
每一层只要"最右边那一个"：BFS 时用处理前的队列长度划出一层，这层最后出队的节点就是答案；DFS 先走右子树，当 depth == len(ans) 时说明这一层还没记录，当前节点就是该层最右。

## 易错点
- 空树返回 []
- 不能只走右链：右子树比左子树浅时，更深的层要从左子树里取
- BFS 要在循环前记下本层节点数，不能在循环里用不断变化的 len(queue)
- DFS 必须先右后左，否则 depth == len(ans) 时记录的是最左节点
