# 46. Permutations

- 链接: https://leetcode.com/problems/permutations/
- 难度: Medium
- 最优解:

## 题型
回溯

## 识别信号
- 返回所有排列，结果数是 n! → 枚举全部方案
- 每个位置可以放任何一个还没用过的数，顺序有意义

## 解题步骤
记 n = len(nums)（≤ 6）。
1. 暴力：枚举所有长度为 n、每位任取 nums 中一个数的序列（n^n 个），再筛掉有重复元素的，O(n^n·n)
2. 瓶颈：绝大多数序列含重复元素，生成之后才被丢弃
3. 回溯 + used 标记：每一层只从还没用过的数里选，选中后标记、递归、再取消标记，只生成合法排列，O(n!·n)
4. 交换法：第 i 层把 nums[i..] 中每个数轮流换到位置 i，递归处理 i + 1，回来后再换回去，不需要 used 数组；复杂度同上，输出本身就有 n! 个长度为 n 的列表，已是下界

## 关键一步
第 i 层决定第 i 个位置放哪个数，只从还没用过的数里选；递归回来后撤销这次选择，再试下一个。

## 易错点
- 收集结果时要拷贝（path[:] 或 nums[:]）
- 回溯时要取消 used 标记或把交换换回去，漏了会让后面的分支出错
- 排列内部顺序有意义，不能像组合题那样只往后选
