# 133. Clone Graph

- 链接: https://leetcode.com/problems/clone-graph/
- 难度: Medium
- 最优解:

## 题型
哈希表 · DFS · BFS

## 识别信号
- 深拷贝一个可能带环的结构（无向图），节点之间互相引用
- 同一个节点会从多条边被走到，需要"原节点 → 克隆节点"的对应关系来避免重复复制和死循环

## 解题步骤
记 V = 节点数，E = 边数。
1. 直接递归复制：新建当前节点，再递归复制每个邻居；无向图里 A 的邻居有 B、B 的邻居又有 A，会无限递归，就算没环也会把同一节点复制多份
2. 瓶颈：不知道某个节点是否已经复制过
3. 优化：哈希表记录 原节点 → 克隆节点；DFS 或 BFS 遍历原图，遇到已在表里的节点直接用它的克隆连边，否则新建克隆、先放进表、再继续处理它的邻居，O(V + E) 时间、O(V) 空间

## 关键一步
新建克隆节点后要先把它放进哈希表，再去处理邻居：这样沿着环绕回来时能直接拿到这个克隆，而不会再复制一次或陷入死循环。

## 易错点
- 输入为 None（空图）时返回 None
- 只有一个节点、没有邻居时，返回一个新的同值节点
- 克隆节点的邻居必须指向克隆节点，不能指向原图节点
- 递归写法要先登记到哈希表再递归邻居，顺序反了会无限递归
