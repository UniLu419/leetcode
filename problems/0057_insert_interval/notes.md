# 57. Insert Interval

- 链接: https://leetcode.com/problems/insert-interval/
- 难度: Medium
- 最优解: 241221.py

## 题型
区间

## 识别信号
- intervals 已按起点排序且互不重叠，插入一个新区间后仍要保持有序、不重叠
- 输入已有序 → 不需要再排序，一遍扫描即可

## 解题步骤
记 n = len(intervals)。
1. 复用合并区间（56 题）：把 newInterval 加进去，排序后合并，O(n log n)
2. 瓶颈：输入本来就有序，排序是多余的
3. 优化：一遍扫描分三段：完全在 newInterval 左边的（end < 新区间 start）原样加入；与它重叠的合并成一个（start 取最小、end 取最大）；完全在右边的原样加入，O(n)

## 关键一步
在有序且不重叠的输入里，和 newInterval 重叠的区间是连续的一段，把这一段和 newInterval 合并成一个区间即可。

## 易错点
- intervals 为空时直接返回 [newInterval]
- newInterval 在所有区间之后：241221.py 用 found 标记，循环结束仍没插入就追加到末尾
- 不重叠直接插入 newInterval 时，别漏掉当前这个区间：原注释"不要忘记处理当前interval"
- 插入后，后面的区间仍可能和刚插入的区间重叠，要继续合并；found 要及时置为 True：原注释"注意更新条件"
