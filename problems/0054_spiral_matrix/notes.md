# 54. Spiral Matrix

- 链接: https://leetcode.com/problems/spiral-matrix/
- 难度: Medium
- 最优解: 241216.py

## 题型
矩阵模拟

## 识别信号
- 按顺时针螺旋顺序输出 m × n 矩阵的所有元素
- 纯过程模拟：右、下、左、上循环转向

## 解题步骤
记 m = 行数，n = 列数。
1. 模拟 + 访问标记：按右、下、左、上的顺序走，碰到边界或已访问的格子就转向，O(m·n) 时间、O(m·n) 额外空间
2. 瓶颈：访问标记矩阵占用额外空间
3. 优化：用 top、bottom、left、right 四个边界代替标记，每走完一条边就把对应边界向内收缩一格，O(m·n) 时间、O(1) 额外空间

## 关键一步
每走完一条边就收缩对应的边界；走下一条边前检查 top ≤ bottom、left ≤ right，避免单行或单列被重复输出。

## 易错点
- 走出边界或碰到已访问格子后，要把坐标退回一步再转向：原注释"将出界的坐标回调"
- 向左、向上走的边界条件含等号：原注释"注意边界条件有等号"
- 一圈结束后要衔接到下一圈的起点：原注释"注意不要漏掉和下一个循环里的第一个while的衔接"
- 单行、单列矩阵
