# 112. Path Sum

- 链接: https://leetcode.com/problems/path-sum/
- 难度: Easy
- 最优解:

## 题型
二叉树 · DFS

## 识别信号
- 判断是否存在一条从根到叶子的路径，路径和等于目标值；路径必须走到叶子

## 解题步骤
记 n = 节点数，h = 树高，w = 最大层宽。
1. 暴力：先收集所有根到叶子的路径，再逐条求和比较，O(n·h) 时间
2. 瓶颈：每条路径都从头重新求和
3. 优化：DFS 往下传"剩余目标值" targetSum − 当前节点值，到叶子时判断剩余值是否等于叶子的值，O(n) 时间、O(h) 栈空间；BFS 队列存 (节点, 到该节点的路径和) 也可以，O(n) 时间、O(w) 空间
4. 找到一条满足的路径就立即返回 True（用 or 短路）

## 关键一步
只在叶子（左右孩子都为空）处判断是否命中目标，往下递归时把目标值减去当前节点的值。

## 易错点
- 空树返回 False，即使 targetSum 为 0
- 只有一个孩子的节点不是叶子：[1, 2]、目标 1 应为 False，不能在空孩子处判定成功
- 节点值和目标值都可能是负数，不能因为累计和超过目标就提前剪枝
