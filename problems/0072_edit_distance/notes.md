# 72. Edit Distance

- 链接: https://leetcode.com/problems/edit-distance/
- 难度: Medium
- 最优解:

## 题型
动态规划

## 识别信号
- 两个字符串，允许插入、删除、替换，求把一个变成另一个的最少操作次数
- 问题可以按两个字符串的前缀拆分：只看两个前缀的最后一个字符怎么处理

## 解题步骤
记 m = len(word1)，n = len(word2)。
1. 暴力递归：比较两串的最后一个字符，相等就都去掉；不相等就分别尝试插入、删除、替换（各 +1）再递归，指数级
2. 瓶颈：子问题只由两个前缀长度 (i, j) 决定，一共只有 (m+1)(n+1) 种，却被反复计算
3. 动态规划：dp[i][j] = word1 前 i 个变成 word2 前 j 个的最少操作数；word1[i−1] == word2[j−1] 时 dp[i][j] = dp[i−1][j−1]，否则 dp[i][j] = 1 + min(dp[i−1][j]（删除）, dp[i][j−1]（插入）, dp[i−1][j−1]（替换））；边界 dp[i][0] = i、dp[0][j] = j；O(mn) 时间、O(mn) 空间
4. 空间优化：按行滚动成一维，左上角的旧值要用一个变量单独保存，O(n) 空间

## 关键一步
只看两个前缀的最后一个字符：删除、插入、替换分别对应从上方、左方、左上方的格子转移过来，字符相同则直接继承左上方。

## 易错点
- 边界不是 0：dp[i][0] = i（删光），dp[0][j] = j（全部插入）
- 一维滚动时 dp[j−1] 已经被本行覆盖，左上角的值要在覆盖之前存下来
- 任意一个字符串为空时，答案是另一个字符串的长度
- 两个字符串相同时答案为 0
