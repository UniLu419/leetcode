# 20. Valid Parentheses

- 链接: https://leetcode.com/problems/valid-parentheses/
- 难度: Easy
- 最优解: 231107.py

## 题型
栈

## 识别信号
- 括号必须按正确顺序闭合：最后打开的必须最先关闭，正是后进先出
- 字符只有三种括号的左、右两种形式

## 解题步骤
记 n = len(s)。
1. 暴力：反复删掉相邻的 ()、[]、{}，直到删不动，再看是否为空，最坏 O(n²)
2. 瓶颈：每删一次都要从头重新扫描
3. 栈：遇到左括号入栈；遇到右括号时栈顶必须是对应的左括号，否则无效；扫完后栈必须为空，O(n)

## 关键一步
右括号必须和栈顶的左括号配对；扫描结束时栈为空才有效。

## 易错点
- 遇到右括号时栈可能是空的（"]"），要先判断再弹出
- 扫完后栈里还剩左括号（"("）也无效，最后要返回 not stack
- 交叉嵌套（"([)]"）时括号数量都对得上但顺序不对，只能靠栈顶判断
