# 73. Set Matrix Zeroes

- 链接: https://leetcode.com/problems/set-matrix-zeroes/
- 难度: Medium
- 最优解: 241218.py

## 题型
矩阵模拟 · 哈希表

## 识别信号
- 原地修改矩阵，某个格子是 0 会影响它所在的整行和整列
- 边扫边改会让新写入的 0 继续"传染"，必须先记录、后修改

## 解题步骤
记矩阵有 m 行 n 列。
1. 暴力：复制一份矩阵，对原矩阵中每个 0，把副本对应的整行整列置 0，O(mn·(m + n)) 时间、O(mn) 空间
2. 瓶颈：同一行、同一列会被反复清零，且复制整个矩阵浪费空间
3. 优化一：先扫一遍，用集合记录哪些行、哪些列含 0，再统一清零，O(mn) 时间、O(m + n) 空间
4. 优化二：用第一行和第一列充当标记数组，另用两个变量记录第一行、第一列本身是否含 0，空间降到 O(1)

## 关键一步
分两遍：先标记含 0 的行和列，再清零；O(1) 空间版本把这些标记存在第一行和第一列里。

## 各版本
| 文件 | 思路 | 时间 | 空间 | 结论 |
| --- | --- | --- | --- | --- |
| 241218.py | 两个 dict 记录含 0 的行和列，再分别把这些行、列清零 | O(mn) | O(m + n) | 通过，空间未达最优（可用第一行和第一列做标记） |

## 易错点
- 不能边扫描边清零，否则新写入的 0 会被当成原本的 0，导致多清
- 用第一行、第一列做标记时，要先单独记下它们本身是否含 0，并且最后才处理第一行和第一列
