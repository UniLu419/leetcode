# 94. Binary Tree Inorder Traversal

- 链接: https://leetcode.com/problems/binary-tree-inorder-traversal/
- 难度: Easy
- 最优解: 231118.py

## 题型
二叉树 · 递归 · 栈

## 识别信号
- 要求按"左子树 → 根 → 右子树"的顺序输出节点值
- 进阶要求不用递归，提示要用显式栈模拟递归

## 解题步骤
记 n = 节点数，h = 树高。
1. 递归：先递归左子树，再记录根，再递归右子树，每个节点访问一次，O(n) 时间、O(h) 递归栈
2. 迭代：用栈模拟递归，一路把左孩子压栈，弹出时记录值并转向右子树，复杂度相同
3. 若要求 O(1) 额外空间，可以用 Morris 遍历（借用空闲的右指针回到父节点）

## 关键一步
中序就是"一路向左走到底，回来时记录当前节点，再去右子树"；递归和栈写法都只是在实现这个顺序。

## 易错点
- 空树要返回 []，递归函数里先判断 root is not None
- 结果列表在递归间共享传递，不要每层新建再拼接，否则会多出复制开销
