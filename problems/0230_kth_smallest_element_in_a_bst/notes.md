# 230. Kth Smallest Element in a BST

- 链接: https://leetcode.com/problems/kth-smallest-element-in-a-bst/
- 难度: Medium
- 最优解:

## 题型
二叉搜索树 · DFS · 栈

## 识别信号
- 树是二叉搜索树，问"第 k 小"的元素
- BST 的中序遍历就是升序，第 k 小 = 中序遍历的第 k 个节点

## 解题步骤
记 n = 节点数，h = 树高。
1. 暴力：遍历所有节点收集值，排序后取下标 k − 1，O(n log n)
2. 瓶颈：没有利用 BST 已经有序这一点
3. 优化一：中序遍历得到升序列表，取下标 k − 1，O(n) 时间、O(n) 空间
4. 优化二：用栈做迭代中序遍历，每弹出一个节点计数加一，数到第 k 个立刻返回，O(h + k) 时间、O(h) 空间
5. 进阶（树频繁增删、反复查询）：每个节点额外记录子树大小，比较 k 和左子树大小决定往左、返回当前节点还是往右，每次查询 O(h)

## 关键一步
中序遍历按从小到大的顺序访问 BST 的节点，所以只要在中序遍历中数到第 k 个被访问的节点就可以停下，它就是答案。

## 易错点
- k 从 1 开始计数
- 递归写法提前找到答案后要能及时停止并把结果传出来（用外部变量记录，或者改用迭代栈）
- 迭代中序：先把左链全部压栈，弹出一个节点后再转向它的右子树
