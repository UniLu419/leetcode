# 399. Evaluate Division

- 链接: https://leetcode.com/problems/evaluate-division/
- 难度: Medium
- 最优解:

## 题型
图 · DFS · 并查集

## 识别信号
- 已知若干 a / b = k，求 x / y；比值可以传递：a / c = (a / b) · (b / c)
- 把变量看成节点、每个等式看成带权的边，查询就变成找一条从 x 到 y 的路径

## 解题步骤
记 E = len(equations)，Q = len(queries)，V = 变量个数。
1. 建图：每个等式 a / b = v 加两条有向边 a → b 权重 v、b → a 权重 1 / v，O(E)
2. 每个查询从 x 出发 DFS/BFS 找 y，沿路把边权乘起来，O(Q·(V + E))；本题 E、Q ≤ 20，这已足够
3. 优化（查询很多时）：带权并查集，每个变量存它与根的比值 weight[x] = x / root(x)，合并两个集合时按等式调整权重；查询时若同根，x / y = weight[x] / weight[y]，否则 −1.0，近似 O((E + Q)·α(V))
4. 另一种：Floyd 式预处理所有变量对的比值，O(V³) 预处理，每个查询 O(1)

## 关键一步
x / y 等于从 x 到 y 路径上各条边比值的乘积：正向边乘 v，反向边乘 1 / v，所以建图时每个等式要同时加上正反两条边。

## 易错点
- 查询里出现没在等式中出现过的变量，结果是 −1.0，即使是 x / x（例 1 的 ["x","x"] 是 −1.0）
- 出现过的变量 a / a = 1.0
- 两个变量不连通时是 −1.0
- DFS 要带 visited，图里有环（正反两条边本身就构成环）
- 变量名是字符串，可以有多个字符（"bc"），不能按单个字符处理
