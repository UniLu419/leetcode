# 224. Basic Calculator

- 链接: https://leetcode.com/problems/basic-calculator/
- 难度: Hard
- 最优解: 241223.py

## 题型
栈 · 字符串模拟

## 识别信号
- 只含 +、−、括号、空格和非负整数的表达式求值，不能用 eval
- 括号可以嵌套，要用栈保存进入括号前的状态

## 解题步骤
记 n = len(s)。
1. 常规做法：遇到 "(" 就把当前结果和符号压栈，遇到 ")" 弹栈合并，O(n)
2. 简化：只有加减，括号的作用只是给里面所有数整体乘上 +1 或 −1，所以只需把每层括号的整体符号压栈
3. 逐字符扫描：数字累积成多位数；遇到运算符或括号时，先把上一个数按当前符号加进答案；"+" 时当前符号取栈顶，"−" 时取栈顶的相反数，"(" 把当前符号压栈，")" 弹栈；O(n)

## 关键一步
每个数最终的正负号 = 它前面运算符的符号 × 外层所有括号的整体符号，栈顶 sign_stack[-1] 就是外层括号的累计符号。

## 易错点
- 原注释：处理加减数学计算除了把数和运算符丢进栈以外还可以把括号前的运算符（1/-1）丢进栈
- 多位数要累积 num = num * 10 + 数字，遇到非数字字符才结算
- 一元负号（"-(2+3)"、"1-(     -2)"）：结算时 num 是 0，加进答案不影响结果
- 循环结束后还要把最后一个数加上
