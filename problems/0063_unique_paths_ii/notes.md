# 63. Unique Paths II

- 链接: https://leetcode.com/problems/unique-paths-ii/
- 难度: Medium
- 最优解:

## 题型
动态规划

## 识别信号
- 网格只能向右或向下走，求从左上到右下的路径条数
- 有障碍格；到某格的路径数 = 到它上方的路径数 + 到它左方的路径数

## 解题步骤
记 m = 行数，n = 列数。
1. 暴力：DFS 枚举所有路径并计数，指数级
2. 瓶颈：到达同一个格子的路径数被反复计算
3. 动态规划：障碍格 dp[i][j] = 0，否则 dp[i][j] = dp[i−1][j] + dp[i][j−1]；起点不是障碍时 dp[0][0] = 1；答案 dp[m−1][n−1]，O(mn) 时间、O(mn) 空间
4. 空间优化：按行滚动，障碍格 dp[j] = 0，否则 dp[j] += dp[j−1]，O(n) 空间

## 关键一步
障碍格的路径数直接置 0，它就自动不会向右边和下边贡献路径；其他格子照常是上方加左方。

## 易错点
- 起点或终点是障碍时答案为 0
- 第一行、第一列不能一律初始化为 1：障碍之后的格子都到不了
- 一维滚动时，每一行的第 0 列也要检查障碍（之前能到，这一行可能被挡住）
- 1×1 网格且不是障碍时答案为 1
