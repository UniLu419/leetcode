# 14. Longest Common Prefix

- 链接: https://leetcode.com/problems/longest-common-prefix/
- 难度: Easy
- 最优解: 241214_2.py

## 题型
字符串模拟

## 识别信号
- 求所有字符串共同的前缀：前缀长度不会超过最短的字符串
- 可以按列（同一个下标）比较所有字符串，遇到第一个不一致就停

## 解题步骤
记 n = len(strs)，m = 最短字符串的长度，S = 所有字符串的总长度。
1. 逐步缩短候选前缀：拿一个字符串当候选，检查所有字符串是否以它开头，不是就去掉最后一个字符再试，O(n·m²)
2. 瓶颈：每缩短一次都从头重新比较
3. 横向比较：前缀先取第一个字符串，依次和后面每个字符串求公共前缀，前缀变空就提前结束，O(S)
4. 纵向比较：从下标 0 开始，检查所有字符串在这一位是否相同，最多比较 n × m 个字符，O(n·m)

## 关键一步
前缀长度以最短字符串为上限；按列逐位比较所有字符串，第一个不一致的位置就是前缀的终点。

## 易错点
- 列表里有空字符串时（[""]、["", "b"]）答案是空串
- 只有一个字符串时答案就是它本身：241214_2.py 的内层循环 range(n − 1) 为空，每一列都算相同
- 纵向比较的列数要以最短字符串的长度为上限，否则下标越界
