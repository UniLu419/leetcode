# 173. Binary Search Tree Iterator

- 链接: https://leetcode.com/problems/binary-search-tree-iterator/
- 难度: Medium
- 最优解:

## 题型
设计 · 二叉搜索树 · 栈

## 识别信号
- 按从小到大的顺序逐个返回 BST 的元素，就是中序遍历
- 进阶要求 next 和 hasNext 均摊 O(1)，并且只用 O(h) 内存

## 解题步骤
记 n = 节点数，h = 树高。
1. 直接做法：构造时中序遍历，把所有值存进列表，next 按下标取、hasNext 比较下标；构造 O(n)，之后每次 O(1)，空间 O(n)
2. 瓶颈：空间 O(n)，不满足 O(h) 的要求
3. 优化：把中序遍历的递归改成显式栈并"暂停"在每一步：构造时把从根开始一路向左的节点全部入栈；next 弹出栈顶（当前最小值），再把它右孩子开始一路向左的节点入栈；hasNext 判断栈是否非空。每个节点入栈、出栈各一次，n 次 next 共 O(n)，均摊 O(1)，空间 O(h)

## 关键一步
栈里保存的是还没访问的左链，栈顶就是下一个最小值；弹出一个节点后，只需把它右子树的整条左链压入栈。

## 易错点
- 弹出节点后要压入的是它的右孩子及其整条左链，不是左子树
- 单次 next 最坏 O(h)，只是均摊 O(1)
- 值可以是 0，hasNext 要看栈是否为空，不要看栈顶值的真假
