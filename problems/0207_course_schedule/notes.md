# 207. Course Schedule

- 链接: https://leetcode.com/problems/course-schedule/
- 难度: Medium
- 最优解:

## 题型
图 · 拓扑排序

## 识别信号
- "上 a 之前必须先上 b"是有向边 b → a，问能否全部上完
- 能全部完成 ⇔ 有向图里没有环

## 解题步骤
记 V = numCourses，E = len(prerequisites)。
1. 暴力：反复扫描所有课程，找一门先修课都已完成的课标记为完成，直到找不到为止，最后看是否全部完成；每轮重新检查所有边，最坏 O(V·(V + E))
2. 瓶颈：每轮都从头扫描所有课程和边，找"现在能上的课"
3. 优化一（BFS 拓扑排序）：建邻接表和入度数组，入度为 0 的课入队；每出队一门课就把它所有后继的入度减 1，减到 0 的入队；出队总数等于 V 则无环，O(V + E)
4. 优化二（DFS 判环）：每个节点三种状态——未访问、访问中、已完成；DFS 中走到"访问中"的节点说明有环，节点的所有后继处理完后标为已完成，O(V + E)

## 关键一步
入度为 0 的课可以马上上，上完后把它从图中删掉、更新后继的入度；不断删除入度为 0 的点，如果最后还有点删不掉，剩下的点一定在环上。

## 易错点
- [a, b] 表示先修 b 才能修 a，边的方向是 b → a
- 没有任何先修关系的课程也要计入，入度为 0 直接入队
- DFS 判环只用"访问过"一种标记会把已经确认安全的节点误判成环，必须区分"访问中"和"已完成"
- 递归 DFS 在一条长链上深度可达 V = 2000，超过 Python 默认递归上限 1000
