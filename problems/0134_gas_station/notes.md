# 134. Gas Station

- 链接: https://leetcode.com/problems/gas-station/
- 难度: Medium
- 最优解: 241214_5.py

## 题型
贪心 · 前缀和

## 识别信号
- 环形路线，从某个起点出发油量全程不能为负，求起点
- 题目保证有解时解唯一；总油量 ≥ 总消耗是有解的充要条件

## 解题步骤
记 n = len(gas)，diff[i] = gas[i] − cost[i]。
1. 暴力：枚举每个起点，绕一圈累加 diff，中途为负就换下一个起点，O(n²)
2. 剪枝：总和为负直接返回 -1；diff 为负的位置不可能是起点；连续同号的 diff 可以合并成一段。这些都只减少常数，最坏仍是 O(n²)
3. 瓶颈：从起点 s 走到 i 时油量第一次为负，s 到 i 之间任何位置作起点也都会在 i 之前或在 i 处断掉（它们少了前面那段非负的累计油量）
4. 贪心：一遍扫描累加 remain，一旦为负就把起点设为 i + 1 并清零；只要总和非负，最后的起点就是答案，O(n) 时间、O(1) 空间

## 关键一步
从 start 出发到 i 时累计油量为负，则 start 到 i 之间都不能当起点，直接把起点跳到 i + 1。

## 易错点
- 原注释："先证明一定有解"：总和 sum(gas) ≥ sum(cost) 时一定有解，贪心最后的 start 才可信
- 累计为负时起点设为 i + 1 且 remain 清零，不是 i
- 241214_5.py 的循环变量叫 n，表示站点下标，不是站点数
