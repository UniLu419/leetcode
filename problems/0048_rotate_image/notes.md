# 48. Rotate Image

- 链接: https://leetcode.com/problems/rotate-image/
- 难度: Medium
- 最优解: 241218.py

## 题型
矩阵模拟

## 识别信号
- n × n 矩阵顺时针旋转 90 度
- 要求原地修改，不能另开一个矩阵

## 解题步骤
记 n = 边长。
1. 新开矩阵：result[j][n − 1 − i] = matrix[i][j]，O(n²) 时间、O(n²) 空间，但题目要求原地
2. 原地按层旋转：从外到内共 n // 2 层，每层上 (i, y)、(y, n − 1 − i)、(n − 1 − i, n − 1 − y)、(n − 1 − y, i) 四个位置构成一个环，一次轮换四个数，O(n²) 时间、O(1) 空间
3. 等价的原地写法：先沿主对角线转置，再把每一行左右翻转

## 关键一步
(i, j) 旋转后到 (j, n − 1 − i)；同一层的四个对应位置构成一个长度为 4 的环，用一个临时变量轮换即可原地完成。

| 241218.py | 按层处理，每层逐个位置做上 → 右 → 下 → 左的四元轮换 | O(n²) | O(1) | 最优 |

## 易错点
- 层数是 n // 2，奇数 n 的中心格不动；241218.py 开头注释写的是 floor((n-1)//2)，对偶数 n 会少一层，代码里实际用的 floor(n / 2) 才对
- 每层每条边只处理 n − 2i − 1 个位置：原注释"由于第一行的最后一个数是右列第一个数，不用再换，不要忘记-1"
- 右列换到下行、下行换到左列时下标要倒序（n − 1 − y）
