# 139. Word Break

- 链接: https://leetcode.com/problems/word-break/
- 难度: Medium
- 最优解:

## 题型
动态规划 · 哈希表

## 识别信号
- 判断字符串能否切分成字典里的单词，单词可以重复使用
- s[:i] 能否切分取决于某个更短的前缀 s[:j] 能否切分、且 s[j:i] 是单词，子问题大量重叠

## 解题步骤
记 n = len(s)，L = 字典中最长单词的长度（≤ 20）。
1. 暴力：从开头递归，尝试每个能匹配的单词再递归剩余部分，最坏指数级（例如 s = "aaa…ab"，字典是 "a"、"aa"、"aaa"、…）
2. 瓶颈：同一个起点"剩下的部分能否切分"被反复求解
3. 记忆化 / 递推：dp[i] 表示 s[:i] 能否切分，dp[0] = True；dp[i] 为真当且仅当存在 j < i 使 dp[j] 为真且 s[j:i] 在字典中；共 O(n²) 对 (j, i)，每次切片加查找 O(n)，O(n³)
4. 优化：字典转成 set；j 只需从 i - L 枚举到 i - 1（单词长度不超过 L），O(n·L²)
5. 也可以对每个位置 i 遍历字典单词用 s.startswith(w, i) 判断，或者建字典树从 i 往后匹配

## 关键一步
把"整串能否切分"拆成"某个前缀能切分 + 最后一段是字典里的单词"：dp[i] = 存在 j 使 dp[j] 为真且 s[j:i] 是单词。

## 易错点
- 贪心地每次取最长（或最短）的匹配会错：s = "cars"、字典 ["car", "ca", "rs"]，取 "car" 后剩下 "s" 无法切分，正确切分是 "ca" + "rs"
- dp 长度是 n + 1，dp[0] = True 表示空串可以切分
- wordDict 是列表，不转成 set 时每次查找是 O(len(wordDict))
- 单词可以重复使用，例 2 里 "apple" 用了两次
