# 151. Reverse Words in a String

- 链接: https://leetcode.com/problems/reverse-words-in-a-string/
- 难度: Medium
- 最优解: 241214.py

## 题型
双指针 · 字符串模拟

## 识别信号
- 以单词为单位反转顺序，同时要去掉首尾空格、把单词间的多个空格压成一个
- 进阶：字符串可变时要求 O(1) 额外空间，提示"整体反转 + 每个单词再反转"

## 解题步骤
记 n = len(s)。
1. 直接做：不带参数的 split() 按连续空白切分并丢掉空串，反转单词列表，再用一个空格 join，O(n) 时间、O(n) 空间
2. 反转单词列表可以用左右双指针交换，等价于 words[::-1]
3. 进阶（字符串可变的语言要求 O(1) 额外空间）：先原地去掉多余空格，再整体反转字符串，最后把每个单词各自反转回来

## 关键一步
不带参数的 split() 一步解决首尾空格和连续空格，剩下只是把单词顺序反过来。

## 易错点
- 用 split(" ") 会因为连续空格产生空串，要用不带参数的 split()
- 原注释：如果是要空间复杂度O（1）的话，可以将字符串去掉冗余空格后整体反转，然后再将每个单词反转
