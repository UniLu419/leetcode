# 228. Summary Ranges

- 链接: https://leetcode.com/problems/summary-ranges/
- 难度: Easy
- 最优解: 241221.py

## 题型
区间 · 双指针

## 识别信号
- 有序、无重复的整数数组，把连续的数合并成区间
- 输出每段连续区间的起点和终点

## 解题步骤
记 n = len(nums)。
1. 一遍扫描：下一个数等于前一个数 + 1 就延伸当前段，否则结束当前段、开始新段，O(n)
2. 每段只需要起点和终点：用段起点 i 和扫描指针 j 两个下标即可，不必存下整段元素
3. 输出：起点等于终点写成 "a"，否则写成 "a->b"

## 关键一步
比较 nums[j] + 1 == nums[j + 1]，决定是延伸当前段还是新开一段。

## 易错点
- 原注释：注意空输入
