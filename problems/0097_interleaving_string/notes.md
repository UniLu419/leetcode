# 97. Interleaving String

- 链接: https://leetcode.com/problems/interleaving-string/
- 难度: Medium
- 最优解:

## 题型
动态规划

## 识别信号
- 判断 s3 能否由 s1 和 s2 各自保持原顺序交错拼成
- s3 下一个字符可能同时等于 s1 和 s2 的下一个字符，不知道该用哪边，需要尝试两种选择
- "s1 用了前 i 个、s2 用了前 j 个"这一状态就决定了后面能否成功

## 解题步骤
记 m = len(s1)，n = len(s2)。
1. 先判断 m + n == len(s3)，不相等直接返回 False，O(1)
2. 暴力：从左往右，s3 的下一个字符等于 s1 或 s2 的下一个字符就分别递归尝试，最坏 O(2^(m+n))
3. 瓶颈：不同的选择顺序会走到同一个 (i, j)，被重复搜索
4. 动态规划：dp[i][j] = s1 前 i 个和 s2 前 j 个能否交错成 s3 前 i + j 个；dp[i][j] = (dp[i−1][j] 且 s1[i−1] == s3[i+j−1]) 或 (dp[i][j−1] 且 s2[j−1] == s3[i+j−1])，dp[0][0] = True；O(mn) 时间、O(mn) 空间（等价于记忆化搜索）
5. 空间优化：按行滚动成一维，O(n) 空间（题目 follow-up 要求只用 O(len(s2)) 额外空间）

## 关键一步
状态只需要 (i, j)：s3 已经匹配的长度一定是 i + j，不用单独记 s3 的下标。

## 易错点
- 长度不相等要先返回 False，否则下标越界或结果错误
- 两边字符都能匹配时不能贪心只走一边，例如 s1 = "aa"、s2 = "ab"、s3 = "aaba"
- 空串：三个都为空返回 True；s1、s2 都为空但 s3 非空返回 False
- 一维滚动时第 0 列只能从上一行转移（只用 s1），要单独处理
