# 22. Generate Parentheses

- 链接: https://leetcode.com/problems/generate-parentheses/
- 难度: Medium
- 最优解:

## 题型
回溯

## 识别信号
- 要生成所有合法的括号串 → 枚举全部方案
- "合法"可以在构造过程中逐字符判断：任何前缀里右括号都不多于左括号，左括号总数不超过 n

## 解题步骤
记 n 为括号对数，答案个数是第 n 个卡特兰数 C_n（约 4^n / n^1.5）。
1. 暴力：枚举全部 2^(2n) 个长度为 2n 的括号串，逐个用计数检查是否合法，O(2^(2n)·n)
2. 瓶颈：绝大多数串不合法，而且很多在前几个字符就已经注定不合法
3. 回溯：逐字符构造，记录已用的左括号数 open 和右括号数 close；open < n 时可以加 "("，close < open 时可以加 ")"，长度到 2n 就收集；只生成合法串，O(C_n·n)

## 关键一步
只在 open < n 时加左括号、只在 close < open 时加右括号：这两个条件保证每一步的前缀都合法，生成出来的就全是答案。

## 易错点
