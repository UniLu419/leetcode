# 23. Merge k Sorted Lists

- 链接: https://leetcode.com/problems/merge-k-sorted-lists/
- 难度: Hard
- 最优解:

## 题型
堆 · 分治 · 链表

## 识别信号
- 合并 k 个已排序的序列，每一步要从 k 个当前最小值里挑出最小的那个
- k 可达 10^4，逐条合并会让前面的节点被反复扫描

## 解题步骤
记 k = len(lists)，N = 所有链表的节点总数。
1. 暴力：把所有值收集起来排序再建链表，O(N log N) 时间、O(N) 空间
2. 逐条合并：结果依次与每条链表做"合并两个有序链表"，O(k·N)
3. 瓶颈：逐条合并时，早合并进来的节点在后面每一次合并里都会再被走一遍
4. 优化一：小顶堆放每条链表的当前头节点，每次弹出最小的接到结果尾部，再把它的 next 推入堆；堆大小不超过 k，O(N log k) 时间、O(k) 空间
5. 优化二：分治两两合并——第一轮合并 (0,1)、(2,3)……，链表数减半，共 log k 轮，每轮走 N 个节点，O(N log k) 时间、O(1) 额外空间（迭代写法）

## 关键一步
下一个要接上的节点只可能是 k 条链表当前头节点中最小的那个；用大小为 k 的小顶堆维护这些头节点，每次取最小只要 O(log k)。

## 易错点
- Python 的 heapq 比较元组时，val 相同会接着比较 ListNode 而抛 TypeError；元组中间放链表下标或计数器作为平局键
- lists 可能为空，也可能含有空链表（None）；None 不能推进堆
- 分治两两合并时 k 为奇数，最后一条链表要原样留到下一轮
- 结果为空时返回 None
