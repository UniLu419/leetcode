# 64. Minimum Path Sum

- 链接: https://leetcode.com/problems/minimum-path-sum/
- 难度: Medium
- 最优解:

## 题型
动态规划

## 识别信号
- 网格从左上走到右下，只能向右或向下，求路径和的最小值
- 每个格子只能从上方或左方到达，到达它的最优值只依赖这两个格子

## 解题步骤
记 m = 行数，n = 列数。
1. 暴力：递归枚举所有路径，共 C(m+n−2, m−1) 条，指数级
2. 瓶颈：到达同一个格子的最小路径和被很多条路径重复计算，而格子只有 m·n 个
3. 动态规划：dp[i][j] = grid[i][j] + min(dp[i−1][j], dp[i][j−1])；第一行只能从左边来、第一列只能从上边来；答案 dp[m−1][n−1]，O(mn) 时间、O(mn) 空间
4. 空间优化：按行滚动，dp[j] = grid[i][j] + min(dp[j], dp[j−1])（dp[j] 是上一行的值，dp[j−1] 是本行刚算好的值），O(n) 空间；也可以直接在 grid 上原地累加

## 关键一步
到达 (i, j) 的最小路径和只取决于到达上方和左方两个格子的最小路径和，按行从左到右填表就能保证用到的值都已算好。

## 易错点
- 第一行、第一列只有一个来源，要单独初始化（或者用 inf 填充边界，但起点 (0, 0) 不能取 min）
- 只有一行或一列时只有一条路径，答案是整行（列）之和
- 原地修改 grid 会破坏输入，面试里要说明这一点
