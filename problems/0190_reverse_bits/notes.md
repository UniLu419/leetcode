# 190. Reverse Bits

- 链接: https://leetcode.com/problems/reverse-bits/
- 难度: Easy
- 最优解:

## 题型
位运算

## 识别信号
- 把整数当作 32 位二进制，要求把这 32 位倒序
- 位数固定为 32，操作次数是常数

## 解题步骤
1. 字符串：format(n, "032b") 补齐 32 位后反转，再用 int(…, 2) 转回整数，O(32)
2. 逐位：循环 32 次，每次取 n 的最低位 n & 1，结果左移一位后把这一位放进最低位，n 右移一位，O(32) 时间、O(1) 空间
3. 进阶（函数被反复调用时）：分治交换——先交换高低 16 位，再在每 16 位内交换高低 8 位，依次到相邻 1 位，每一步用一个掩码完成，共 5 步，O(1)；或按字节查表缓存

## 关键一步
必须固定循环 32 次（而不是 n 变成 0 就停）：原来高位上的 0 也要依次移到结果的低位，结果才是完整的 32 位倒序。

## 易错点
- 用 bin(n) 时不会补前导零，直接反转位数不对，要先补齐到 32 位
- n 变成 0 就提前退出会少左移几次，结果偏小（例：n = 2 的结果是 2^30 = 1073741824）
- 在 Python 里输入和输出都是普通整数；题目保证 n 是偶数，所以结果的最高位是 0
