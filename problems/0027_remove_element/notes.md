# 27. Remove Element

- 链接: https://leetcode.com/problems/remove-element/
- 难度: Easy
- 最优解: 231107.py

## 题型
双指针

## 识别信号
- 原地删除所有等于 val 的元素，返回剩下的个数 k
- 只检查前 k 个元素，顺序可以改变，后面的内容不用管

## 解题步骤
记 n = len(nums)。
1. 暴力：遇到 val 就删除并把后面的元素前移，O(n²)
2. 瓶颈：每次删除都要搬移
3. 优化：读写双指针。读指针遍历每个元素，写指针 i 只在元素不等于 val 时写入并前进，O(n)

## 关键一步
不等于 val 的元素依次覆盖到 nums[i]，遍历结束时 i 就是保留的个数。

| 231107.py | 读写双指针，不等于 val 的覆盖到写指针位置 | O(n) | O(1) | 最优 |

## 易错点
- 空数组返回 0
- 全部等于 val 时返回 0，数组内容不用管
- 写指针永远不超过读指针，所以覆盖不会丢失还没读到的元素
