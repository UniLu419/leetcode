# 295. Find Median from Data Stream

- 链接: https://leetcode.com/problems/find-median-from-data-stream/
- 难度: Hard
- 最优解:

## 题型
堆 · 设计

## 识别信号
- 数据流不断插入，插入和查询中位数交错进行（最多 5·10^4 次调用）
- 中位数只取决于"较小一半里最大的数"和"较大一半里最小的数"，不需要整体有序

## 解题步骤
记 n = 已插入的元素个数。
1. 暴力：addNum 直接追加，findMedian 时排序取中间，addNum O(1)，findMedian O(n log n)
2. 优化一：始终保持列表有序，插入时二分找位置（bisect.insort），addNum O(n)（插入要搬移元素），findMedian O(1)
3. 瓶颈：只需要中间一两个数，却维护了整个有序序列
4. 优化二：两个堆——大顶堆 lo 存较小的一半，小顶堆 hi 存较大的一半，并保持 len(lo) == len(hi) 或 len(lo) == len(hi) + 1；中位数由两个堆顶得到，addNum O(log n)，findMedian O(1)

## 关键一步
新数先放进 lo，再把 lo 的堆顶移到 hi；若此时 hi 比 lo 多，再把 hi 的堆顶移回 lo。这样既保证 lo 里每个数都不大于 hi 里每个数，又保证两边个数平衡，中位数就是 lo 的堆顶或两个堆顶的平均。

## 易错点
- Python 的 heapq 只有小顶堆，lo 存相反数模拟大顶堆，取堆顶时要再取反
- 总个数为偶数时返回两个堆顶的平均，用 / 得到小数（例：1 和 2 得 1.5）
- 只和一个堆顶比较大小就直接入堆、不做再平衡，两边个数会失衡
- 负数同样适用：-1 和 -2 的中位数是 -1.5
