# 222. Count Complete Tree Nodes

- 链接: https://leetcode.com/problems/count-complete-tree-nodes/
- 难度: Medium
- 最优解:

## 题型
二叉树 · 递归 · 二分查找

## 识别信号
- 树是完全二叉树：除最后一层外都是满的，最后一层的节点都靠左
- 题目要求设计低于 O(n) 的算法，不能把节点逐个数一遍

## 解题步骤
记 n = 节点数，h = 树高（约 log n）。
1. 暴力：任意遍历数节点，O(n)
2. 瓶颈：没有利用完全二叉树的形状；高度为 h 的满二叉树节点数可以直接算出：2^h − 1
3. 优化一（比较左右子树高度）：沿最左链分别求左子树高度 lh 和右子树高度 rh。若 lh == rh，说明最后一层已延伸到右子树，左子树是高度 lh 的满二叉树，它加上根共 2^lh 个节点，再递归数右子树；否则右子树是高度 rh 的满二叉树，它加上根共 2^rh 个节点，再递归数左子树。每层只递归一侧，每次求高度 O(h)，总 O(h²) = O(log² n)
4. 优化二（二分最后一层）：最后一层最多 2^(h−1) 个位置，二分最后一层有多少个节点；判断第 i 个位置是否有节点时，按 i 的二进制位从根往左/右走，O(h)；总 O(h²) = O(log² n)

## 关键一步
完全二叉树的左右子树中至少有一棵是满二叉树，满二叉树的节点数由高度直接算出，所以每一层只需要递归另一棵子树。

## 易错点
- 高度要沿最左链求（完全二叉树最左边的链最长）
- 2 的幂用 1 << h；高度从 0 还是从 1 起算要和公式对上，差一就会多算或少算根节点
- 空树返回 0
