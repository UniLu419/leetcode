# 7. Reverse Integer

- 链接: https://leetcode.com/problems/reverse-integer/
- 难度: Medium
- 最优解: 231107.java

## 题型
数学

## 识别信号
- 按十进制位反转一个整数：反复用 x % 10 取末位、x / 10 去掉末位
- 结果超出 32 位有符号整数范围要返回 0，且题目假设不能存 64 位整数，溢出必须在计算之前判断

## 解题步骤
记 d = x 的十进制位数（最多 10 位），INT_MAX = 2³¹ − 1，INT_MIN = −2³¹。
1. 直接做法：转成字符串反转再转回整数，用 64 位整数判断越界；但题目不允许使用 64 位整数
2. 逐位弹出：pop = x % 10，x /= 10，rev = rev × 10 + pop，O(d)
3. 瓶颈：rev × 10 + pop 本身就可能溢出，不能算完再检查
4. 乘之前判断：rev > INT_MAX / 10，或 rev == INT_MAX / 10 且 pop > 7，就会上溢；负数方向对称，用 INT_MIN / 10 和 pop < −8

## 关键一步
执行 rev = rev × 10 + pop 之前，先拿 rev 和 INT_MAX / 10（负数用 INT_MIN / 10）比较，相等时再看末位是否超过 7（负数是低于 −8）。

## 易错点
- Java 的 % 和 / 向 0 取整，负数弹出的 pop 也是负数，所以正负数共用一个循环；Python 的 % 和 // 向下取整，照抄会出错，要先取绝对值再补符号
- 越界判断必须在乘 10 之前做；上界末位 7、下界末位 −8 分别来自 2147483647 和 −2147483648
- 末尾有 0（120 → 21）和 x = 0 都不需要特判
