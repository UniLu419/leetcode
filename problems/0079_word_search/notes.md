# 79. Word Search

- 链接: https://leetcode.com/problems/word-search/
- 难度: Medium
- 最优解:

## 题型
回溯 · DFS

## 识别信号
- 在网格上沿上下左右相邻的格子拼出单词，同一格不能重复使用 → 路径搜索 + 访问标记
- 只问"是否存在"一条路径，但不同路径会共用格子 → 走不通时要撤销标记再试别的方向

## 解题步骤
记网格为 m×n，L = len(word)。
1. 基本解：从每个格子出发 DFS，第 i 步要求格子字符等于 word[i]；走过的格子临时标记，四个方向都失败后恢复；最坏 O(m·n·4·3^(L−1))
2. 瓶颈：字符根本不够的情况（例如全是 A 的棋盘找结尾为 B 的单词）也要穷举所有路径才失败
3. 剪枝一：先统计棋盘上每个字符的个数，单词需要的某个字符不够就直接返回 False；单词比格子总数还长也直接返回 False，O(m·n + L)
4. 剪枝二：如果 word 首字母在棋盘上出现的次数比尾字母多，就把 word 反过来搜，起点更少、更早失败
5. 细节：访问标记直接把格子改成 "#"，回溯时还原，不需要额外的 visited 数组

## 关键一步
进入格子时标记、四个方向都试完后恢复：这样一条路径不会重复用格子，而失败的路径也不会挡住其他路径。

## 易错点
- 返回 False 之前一定要把格子恢复成原字符，否则别的起点的搜索会被错误阻断
- 匹配到最后一个字符就返回 True，不要再往下检查越界
- 单格棋盘、单词长度为 1 的边界
- 不做字符计数剪枝的回溯，在"全是同一字母"的棋盘上会超时
