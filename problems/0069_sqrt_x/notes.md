# 69. Sqrt(x)

- 链接: https://leetcode.com/problems/sqrtx/
- 难度: Easy
- 最优解: 231107.py

## 题型
二分查找 · 数学

## 识别信号
- 求满足 k² ≤ x 的最大整数 k，而 k² 随 k 单调递增
- 不允许使用内置的开方或幂运算；x 最大到 2^31 − 1

## 解题步骤
1. 暴力：k 从 0 往上试，直到 (k + 1)² > x，O(√x)，x 接近 2^31 时约 4.6 万次
2. 瓶颈：k² 对 k 单调，逐个试探没有利用单调性
3. 二分查找：在 [0, x] 上二分，找最大的 k 使 k² ≤ x，O(log x)
4. 牛顿迭代：g ← (g + x / g) / 2，从 √x 上方快速收敛，迭代次数也是 O(log x) 级别，收敛后取整数部分

## 关键一步
k² ≤ x 对 k 单调，二分找最后一个满足的 k；牛顿迭代则用切线逼近 √x，整数部分稳定后即为答案。

## 易错点
- x = 0 时初始猜测为 0，再算 x / g 会除零；231107.py 先判断返回条件，0 在第一轮就直接返回
- 浮点牛顿迭代要确认取整没有误差：231107.py 在 x < 2·10^5 以及 2^31 以下最后 2·10^5 个值上与精确整数平方根逐一对比，结果一致
- 二分写法里 mid * mid 在其他语言可能溢出，可改为 mid ≤ x / mid
