# 67. Add Binary

- 链接: https://leetcode.com/problems/add-binary/
- 难度: Easy
- 最优解: 231107.py

## 题型
字符串模拟 · 位运算

## 识别信号
- 两个二进制字符串相加，长度可达 10^4，不能指望转成固定宽度的整数（其他语言会溢出）
- 逐位相加加进位，和竖式加法一样

## 解题步骤
记 m = len(a)，n = len(b)，L = max(m, n)。
1. 直接法：转成整数相加再转回二进制串；Python 可行，但依赖大整数
2. 逐位模拟：从最低位开始，每一位 = a 的位 + b 的位 + 进位，写下本位，进位传给下一位，O(L)
3. 实现细节：把两个串左侧补 0 到相同长度，并多留一位给最高位进位，循环里就不用判断下标越界

## 关键一步
每一位的和 = a 位 ⊕ b 位 ⊕ 进位，新进位 = 三者中至少两个为 1；从右往左一遍扫完。

## 各版本
| 文件 | 思路 | 时间 | 空间 | 结论 |
| --- | --- | --- | --- | --- |
| 231107.py | 两串左补 0 到 L + 1 位，每位用两次半加器（异或求和、与求进位），最后去掉多余的前导 0 | O(m + n) | O(m + n) | 最优 |

## 易错点
- 最高位可能多出一位进位（"11" + "1" = "100"），所以结果预留 L + 1 位
- "0" + "0" 要返回 "0"：231107.py 只在首位是 "0" 时去掉这一位，不会把结果删成空串
- 两次半加器的进位不会同时为 1（第一次有进位时本位和为 0），所以 new_inc or inc 就是正确的进位
