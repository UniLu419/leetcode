# 103. Binary Tree Zigzag Level Order Traversal

- 链接: https://leetcode.com/problems/binary-tree-zigzag-level-order-traversal/
- 难度: Medium
- 最优解:

## 题型
二叉树 · BFS

## 识别信号
- 按层输出，但相邻两层方向交替（左到右、右到左）
- 本质是层序遍历，只是写入每层结果时方向不同

## 解题步骤
记 n = 节点数，w = 最宽一层的节点数。
1. 直觉做法（错误）：在奇数层改成先入队右孩子再入队左孩子——这会把下一层的入队顺序也打乱，更深的层就错了
2. 暴力：先做普通层序遍历，再把第 1、3、5… 层（从 0 计）反转，O(n) 时间、O(n) 空间
3. 优化：遍历顺序保持普通层序（始终先左后右入队），只在写入本层结果时按层号决定方向：偶数层 append，奇数层 appendleft（用双端队列），省去事后反转，O(n) 时间、O(w) 额外空间

## 关键一步
节点的遍历顺序永远和普通层序遍历一样，"之字形"只体现在把值写进本层列表的方向上：根据层号奇偶选择从尾部追加还是从头部插入。

## 易错点
- 不要通过改变孩子的入队顺序来实现之字形，会影响后续所有层
- 第 0 层（根）从左到右，第 1 层从右到左
- 空树返回 []
- list.insert(0, x) 是 O(len)，从头部插入用 deque.appendleft
