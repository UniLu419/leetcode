# 86. Partition List

- 链接: https://leetcode.com/problems/partition-list/
- 难度: Medium
- 最优解:

## 题型
链表 · 双指针

## 识别信号
- 按和 x 的大小关系把链表分成前后两段，并且每段内部要保持原来的相对顺序（稳定划分）
- 操作对象是链表节点，可以直接摘下节点重新连接

## 解题步骤
记 n = 链表长度。
1. 暴力：把所有值取到数组里，先收集小于 x 的、再收集不小于 x 的，按这个顺序回填或新建链表，O(n) 时间、O(n) 空间
2. 瓶颈：多用了 O(n) 的数组，没有利用链表可以直接摘节点、拼接的特点
3. 优化：建两个哑节点，分别作为"小于 x"和"不小于 x"两条新链表的表头，各带一个尾指针；遍历原链表，把每个节点接到对应链表的尾部，O(n) 时间、O(1) 空间
4. 收尾：小链表的尾部接上大链表的第一个节点，大链表尾部的 next 置为空

## 关键一步
用两个哑节点分别串起小于 x 和不小于 x 的节点，每个节点都只追加到各自链表的尾部，原有相对顺序自然保留，最后把两条链表首尾相接。

## 易错点
- 大链表尾节点的 next 必须置为空，否则它仍指向原链表里的某个节点，会形成环（样例 1 中 5 原本指向 2）
- 等于 x 的节点放在后半段，只有严格小于 x 的才放前面
- 空链表、全部小于 x、全部不小于 x：哑节点写法不需要特判，返回小链表哑节点的 next 即可
- 不要用交换节点值的方式划分，那样会打乱相对顺序
