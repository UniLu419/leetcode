# 452. Minimum Number of Arrows to Burst Balloons

- 链接: https://leetcode.com/problems/minimum-number-of-arrows-to-burst-balloons/
- 难度: Medium
- 最优解: 241223.py

## 题型
贪心 · 区间 · 排序

## 识别信号
- 一组区间，用最少的"点"覆盖所有区间（一支箭就是一个 x 坐标）
- 端点相接也算重叠（x_start ≤ x ≤ x_end）

## 解题步骤
记 n = len(points)。
1. 暴力：枚举射箭位置组合，指数级
2. 观察：一组能被同一支箭射穿的气球，等价于它们的交集非空；排序后相邻处理即可
3. 贪心：按起点排序，维护当前这一组的交集 [左, 右]；下一个气球起点 ≤ 交集右端就并入并把交集收窄，否则开新的一组（多一支箭），O(n log n)
4. 等价写法：按终点排序，箭射在当前终点，跳过所有起点 ≤ 该终点的气球

## 关键一步
按起点排序后，当前组的交集右端是 min(各终点)；新气球起点 ≤ 这个右端就能共用一支箭，否则必须再射一支。

## 易错点
- 端点相接也能一起射穿，判断用 ≥ / <（ans[-1][1] < points[i][0] 才开新组）：原注释"注意大小于"
- ans.append(points[i]) 存的是原输入里的同一个列表，后面收缩交集会改到它；这里已处理过不再读取，所以结果不受影响
