# 98. Validate Binary Search Tree

- 链接: https://leetcode.com/problems/validate-binary-search-tree/
- 难度: Medium
- 最优解:

## 题型
二叉搜索树 · DFS · 递归

## 识别信号
- 判断一棵树是否满足 BST 定义：左子树所有节点都小于根、右子树所有节点都大于根，且左右子树也都是 BST
- 关键是"整棵子树"，不只是直接孩子

## 解题步骤
记 n = 节点数，h = 树高。
1. 直觉做法（错误）：只比较每个节点和它的左右孩子；反例 [5,4,6,null,null,3,7]，3 在 5 的右子树里却小于 5
2. 暴力：对每个节点求左子树的最大值和右子树的最小值来比较，退化成链时 O(n²)
3. 瓶颈：子树的最大值/最小值被反复计算
4. 优化一：自顶向下传递取值范围 (low, high)：进入左子树时上界收紧为当前值，进入右子树时下界收紧为当前值，每个节点检查一次，O(n) 时间、O(h) 空间
5. 优化二（等价）：中序遍历必须严格递增，遍历时和上一个访问的值比较，O(n) 时间、O(h) 空间

## 关键一步
每个节点的合法取值是一个开区间 (low, high)，它由路径上所有祖先共同决定：往左走把 high 改成当前节点值，往右走把 low 改成当前节点值，节点值不在区间内就不是 BST。

## 易错点
- 必须严格小于/大于，相等的值不合法（[2,2,2] 返回 false）
- 节点值可以取到 −2^31 和 2^31 − 1，初始边界用 float('-inf') / float('inf') 或 None，不能用 32 位整数的最值
- 只比较父子是错的，要和所有祖先给出的范围比较
- 中序写法里 prev 的初值同样不能用整数最小值
