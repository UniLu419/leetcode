# 5. Longest Palindromic Substring

- 链接: https://leetcode.com/problems/longest-palindromic-substring/
- 难度: Medium
- 最优解: 231107.java

## 题型
双指针

## 识别信号
- 求最长的回文连续子串：回文关于中心对称，从中心向两边扩展就能枚举出所有回文
- len(s) ≤ 1000，O(n²) 可以接受

## 解题步骤
记 n = len(s)。
1. 暴力：枚举所有子串 O(n²)，逐个判断是否回文 O(n)，共 O(n³)
2. 瓶颈：大量子串共享同一个中心，判断时在重复比较
3. 中心扩展：回文中心共 2n − 1 个（n 个单字符中心、n − 1 个相邻两字符之间的中心），从每个中心用左右两个指针向外扩展到不相等为止，共 O(n²) 次比较，O(1) 额外空间
4. 只在扩展结束时记录起止下标，最后截一次子串，避免每扩展一步都复制子串

## 关键一步
以每个字符、以及每两个相邻字符之间为中心，左右指针同时向外扩展，字符相等就继续；奇数长度和偶数长度的回文要分别枚举中心。

## 易错点
- 偶数长度的回文（"cbbd" → "bb"）没有中心字符，必须单独枚举两字符之间的中心
- 扩展时左指针不能小于 0、右指针不能超过 n − 1：231107.java 用 j ≤ i 和 j < n − i（偶数中心为 j < n − i − 1）控制
- 有多个等长答案时（"babad" 的 "bab" 和 "aba"）返回任意一个都对
