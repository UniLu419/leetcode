# 70. Climbing Stairs

- 链接: https://leetcode.com/problems/climbing-stairs/
- 难度: Easy
- 最优解: 231107.py

## 题型
动态规划

## 识别信号
- 求"有多少种走法"，每一步只有固定几种选择（1 阶或 2 阶）
- 到第 i 阶的方案数只依赖前一两阶的结果

## 解题步骤
记 f(i) = 爬到第 i 阶的方法数。
1. 暴力递归：f(n) = f(n − 1) + f(n − 2)，不记忆会大量重复计算，O(2^n)
2. 瓶颈：同一个 f(i) 被反复计算
3. 自底向上 DP（或记忆化）：用数组从小到大填 f(i)，O(n) 时间、O(n) 空间
4. f(i) 只依赖前两项，用两个变量滚动，空间降到 O(1)

## 关键一步
最后一步不是跨 1 阶就是跨 2 阶，所以 f(n) = f(n − 1) + f(n − 2)，就是斐波那契数列。

## 各版本
| 文件 | 思路 | 时间 | 空间 | 结论 |
| --- | --- | --- | --- | --- |
| 231107.py | 自底向上 DP 数组，a[0] = 1，a[1] = 2，a[i] = a[i − 1] + a[i − 2] | O(n) | O(n) | 通过，空间未达最优（可用两个变量滚动） |

## 易错点
- n 为 1 或 2 时直接返回 n，否则 n = 1 时数组长度为 1，写 a[1] 会越界：231107.py 用 if n < 3: return n 先处理
- 数组下标从 0 开始，a[i] 表示第 i + 1 阶的方法数，所以返回 a[n − 1]
