# 322. Coin Change

- 链接: https://leetcode.com/problems/coin-change/
- 难度: Medium
- 最优解:

## 题型
动态规划

## 识别信号
- 每种硬币数量无限，求凑出目标金额的最少硬币数（完全背包求最小值）
- 先用大面额的贪心不一定最优，例如 coins = [1, 3, 4]、amount = 6

## 解题步骤
记 m = len(coins)，A = amount。
1. 暴力：递归枚举每一步用哪枚硬币，指数级
2. 瓶颈：同一个剩余金额被反复求解
3. 记忆化搜索：f(a) = 1 + min(f(a - c))，缓存 0..A 的结果，O(m·A) 时间、O(A) 空间；递归深度可达 A，Python 默认递归上限 1000 不够
4. 递推：dp[0] = 0，其余初始化为无穷大；dp[a] = min(dp[a - c] + 1)，对所有 c ≤ a 取最小，O(m·A) 时间、O(A) 空间
5. 另一个视角：BFS，从金额 0 出发每一步加一枚硬币，第一次到达 A 时的层数就是答案，同样 O(m·A)

## 关键一步
dp[a] = min(dp[a - c] + 1)：凑出 a 的最优方案去掉最后一枚硬币 c 之后，剩下的一定是凑出 a - c 的最优方案。

## 易错点
- 凑不出要返回 -1；"无穷大"可以用 A + 1，最后判断 dp[A] > A
- amount = 0 时返回 0
- 贪心反例：[1, 3, 4] 凑 6，贪心 4 + 1 + 1 用 3 枚，最优 3 + 3 只用 2 枚
- 面额可达 2^31 - 1，远大于 amount，c > a 的硬币要跳过
