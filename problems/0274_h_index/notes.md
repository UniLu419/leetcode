# 274. H-Index

- 链接: https://leetcode.com/problems/h-index/
- 难度: Medium
- 最优解: 241211.py

## 题型
排序 · 哈希计数

## 识别信号
- 求最大的 h，使"至少有 h 个数 ≥ h"，答案随排序后的位置单调变化
- h 不会超过数组长度 n，引用数大于 n 的都可以当作 n 处理（可以按次数分桶计数）

## 解题步骤
记 n = len(citations)。
1. 暴力：枚举 h = n..0，每次数一遍有多少篇引用 ≥ h，O(n²)
2. 瓶颈：每个 h 都重新数一遍
3. 优化一：降序排序后，第 i 篇（从 0 开始）满足 citations[i] ≥ i + 1 就说明至少有 i + 1 篇引用 ≥ i + 1，条件对 i 单调，最后一个满足的 i + 1 就是答案，O(n log n)
4. 优化二：h 最大为 n，用长度 n + 1 的计数数组统计每个引用数（超过 n 的记到 n），从 n 往下累加篇数，第一次累计篇数 ≥ 当前下标时即为答案，O(n)

## 关键一步
降序排序后，citations[i] ≥ i + 1 等价于"前 i + 1 篇的引用都至少是 i + 1"，所以 h 就是满足这个条件的最大 i + 1。

## 易错点
- 比较的是 citations[i] ≥ i + 1，不是 ≥ i（下标从 0 开始）
- 全是 0 时答案是 0；只有一篇且引用很大（如 [100]）时答案是 1，h 不会超过 n
