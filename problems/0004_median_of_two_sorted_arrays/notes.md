# 4. Median of Two Sorted Arrays

- 链接: https://leetcode.com/problems/median-of-two-sorted-arrays/
- 难度: Hard
- 最优解:

## 题型
二分查找 · 分治

## 识别信号
- 两个有序数组求整体的中位数，要求 O(log(m + n))，不能真的合并
- 中位数 = 合并后第 k 小的元素（或中间两个的平均），而"第 k 小"可以每次排除一半候选

## 解题步骤
记 m = len(nums1)，n = len(nums2)。
1. 暴力：合并成一个有序数组取中间，O(m + n) 时间、O(m + n) 空间
2. 双指针归并，走到第 (m + n) // 2 个元素就停，O(m + n) 时间、O(1) 空间
3. 瓶颈：题目要求对数复杂度，不能逐个走
4. 求第 k 小：比较两个数组各自第 k // 2 个元素，较小那侧的前 k // 2 个都不可能是第 k 小，整体丢掉，k 减去丢掉的个数；某个数组空了就直接取另一个；O(log(m + n))
5. 二分切分：保证 nums1 是较短的，在 nums1 上二分切点 i（左边取 i 个），nums2 的切点 j = (m + n + 1) // 2 − i；要求 nums1[i − 1] <= nums2[j] 且 nums2[j − 1] <= nums1[i]，不满足就向一侧移动 i；切对后由左半最大值和右半最小值算中位数；O(log min(m, n))

## 关键一步
中位数把合并后的数组切成个数相等的左右两半；在短数组上二分切点 i，长数组的切点 j 就由总长度定死，只需检查交叉的两对元素是否满足左半 ≤ 右半。

## 易错点
- 必须在较短的数组上二分，否则 j 可能变成负数或超过 n
- 切点在边界时，不存在的元素用 −∞（左侧）和 +∞（右侧）代替
- j 用 (m + n + 1) // 2 − i 时左半多放一个：总长为奇数时中位数是左半最大值，偶数时是左半最大值和右半最小值的平均
- 返回值是浮点数
- 其中一个数组可能为空
