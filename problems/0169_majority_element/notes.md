# 169. Majority Element

- 链接: https://leetcode.com/problems/majority-element/
- 难度: Easy
- 最优解: 241211.py

## 题型
哈希计数 · 排序

## 识别信号
- 多数元素的出现次数严格大于 n / 2，并且保证存在
- 进阶要求 O(n) 时间、O(1) 空间

## 解题步骤
记 n = len(nums)。
1. 暴力：对每个元素再数一遍它的出现次数，O(n²)
2. 哈希计数：一遍统计每个值的出现次数，取次数最多的，O(n) 时间、O(n) 空间
3. 排序：多数元素占了一半以上的位置，排序后下标 n // 2 处一定是它，O(n log n)
4. 进阶（摩尔投票）：维护一个候选值和计数，遇到相同值计数 +1、不同值 −1，计数为 0 时换候选；多数元素的票抵消不完，O(n) 时间、O(1) 空间

## 关键一步
多数元素超过一半，和其他元素两两抵消后剩下的一定是它；排序版本里，它的连续段一定覆盖下标 n // 2。

## 各版本
| 文件 | 思路 | 时间 | 空间 | 结论 |
| --- | --- | --- | --- | --- |
| 241211.py | 字典计数，再遍历找次数最多的键 | O(n) | O(n) | 通过，空间未达最优 |
| 241211_2.py | 原地排序后取 nums[len(nums) // 2] | O(n log n) | O(n)（排序的临时空间） | 通过，时间未达最优 |

## 易错点
- 不论 n 奇偶，下标 n // 2 都落在多数元素的连续段里
- 241211.py 把变量命名为 max，遮蔽了内置函数 max
- 排序版会修改输入数组
