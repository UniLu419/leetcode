# 110. Balanced Binary Tree

- 链接: https://leetcode.com/problems/balanced-binary-tree/
- 难度: Easy
- 最优解: 231118_2.py

## 题型
二叉树 · 递归

## 识别信号
- 判断每个节点左右子树高度差是否都不超过 1
- 既要子树的"是否平衡"，又要子树的"高度"，适合后序遍历一次返回两样信息

## 解题步骤
记 n = 节点数，h = 树高。
1. 自顶向下：对每个节点分别求左右子树高度并比较，再递归检查左右子树；高度被反复计算，平衡树 O(n log n)，链状树 O(n²)
2. 瓶颈：同一棵子树的高度被每个祖先重新算一遍
3. 自底向上：后序遍历一次，返回子树高度；一旦发现不平衡就返回 -1 并一路向上传递，O(n) 时间、O(h) 递归栈

## 关键一步
用 -1 表示"已不平衡"，非负数表示高度，一个返回值同时带回两种信息，每个节点只算一次。

## 易错点
- 只检查根的左右高度差不够，每个节点都要检查：[1,2,2,3,null,null,3,4,null,null,4] 根的两侧高度相同，但子树不平衡
- 原注释："使用-1记录false，非负数记录高度"；左子树已返回 -1 时直接返回，不必再算右子树
- 空树是平衡的
