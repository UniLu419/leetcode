# 88. Merge Sorted Array

- 链接: https://leetcode.com/problems/merge-sorted-array/
- 难度: Easy
- 最优解: 231118_4.py

## 题型
双指针

## 识别信号
- 两个有序数组合并，结果要原地写进 nums1
- nums1 尾部预留了 n 个空位

## 解题步骤
记 m、n 为两个数组的有效长度。
1. 暴力：把 nums2 拷到 nums1 尾部再排序，O((m + n)·log(m + n))
2. 正向双指针 + 插入：nums2 的元素更小时，把 nums1 后面的元素整体后移一位再插入，每次插入 O(m + n)，总共 O((m + n)·n)
3. 瓶颈：从前往后写会覆盖 nums1 中还没读的元素，只能搬移或另开数组。正向双指针归并到辅助数组再拷回：O(m + n) 时间，但要 O(m + n) 额外空间
4. 逆向双指针：从两个数组的末尾开始比较，把较大的写到 nums1 末尾的空位，O(m + n) 时间、O(1) 空间

## 关键一步
从后往前填：nums1 尾部的空位足够放下所有较大的元素，写指针永远不会越过 nums1 的读指针，不会覆盖未读元素。

## 易错点
- n = 0 时 nums1 不变；m = 0 时要把 nums2 全部拷进去（[0], 0, [1], 1）
- 逆向双指针：nums2 先用完时，剩下的 nums1 元素已在原位；nums1 先用完时，要把 nums2 剩下的元素继续拷完
- 原注释说"倒序双指针慢"，但从复杂度看它是唯一 O(1) 额外空间的线性解
