# 239. Sliding Window Maximum

- 链接: https://leetcode.com/problems/sliding-window-maximum/
- 难度: Hard
- 最优解: 241211_2.py

## 题型
单调队列 · 堆 · 滑动窗口

## 识别信号
- 固定长度 k 的滑动窗口，求每个窗口的最大值
- n 可达 10^5、k 也可以很大，每个窗口重新求最大值会超时

## 解题步骤
记 n = len(nums)。
1. 暴力：每个窗口切片后求 max，O(n·k)
2. 瓶颈：相邻窗口只差一个元素，却每次都重新扫 k 个元素
3. 优化一：大顶堆存 (值, 下标)，取堆顶前先弹出下标已离开窗口的元素（延迟删除），O(n log n)
4. 优化二：双端队列存下标、对应的值单调递减；新元素入队前从队尾弹掉所有不大于它的元素，队首离开窗口就弹出，队首即窗口最大值；每个元素进出各一次，O(n)

## 关键一步
一个元素如果比它后面进来的元素小，它在之后的任何窗口里都不可能是最大值，可以直接丢掉，所以队列保持单调递减。

## 易错点
- 堆只在堆顶过期时才弹出，堆里可能残留已离开窗口的元素，所以要连下标一起存
- 原注释：若最大值已经不在窗口内则弹出；过期的判断条件是下标 ≤ i − k
- Python 的 heapq 是小顶堆，存 −nums[i] 来模拟大顶堆
