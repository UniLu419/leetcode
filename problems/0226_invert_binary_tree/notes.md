# 226. Invert Binary Tree

- 链接: https://leetcode.com/problems/invert-binary-tree/
- 难度: Easy
- 最优解:

## 题型
二叉树 · 递归

## 识别信号
- 每个节点做同一件事（交换左右孩子），整棵树的结果由左右子树各自的结果拼成

## 解题步骤
记 n = 节点数，h = 树高，w = 最大层宽。
1. 递归：先翻转左右子树，再交换当前节点的左右孩子（或先交换再递归），每个节点处理一次，O(n) 时间、O(h) 栈空间，已是最优
2. 迭代：用队列按层（或用栈）取出节点，交换它的左右孩子，再把非空孩子放回队列，O(n) 时间、O(w) 空间，树很深时不受递归深度限制

## 关键一步
对每个节点交换它的左右孩子，左右子树再各自做同样的事；先交换还是先递归都可以，不影响结果。

## 易错点
- 空树返回 None
- 先写 root.left = 翻转(root.right)、再写 root.right = 翻转(root.left)，第二句用到的是已被覆盖的 left；要先保存，或用 a, b = b, a 同时赋值
- 最后要返回根节点
