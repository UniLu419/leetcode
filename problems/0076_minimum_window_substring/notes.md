# 76. Minimum Window Substring

- 链接: https://leetcode.com/problems/minimum-window-substring/
- 难度: Hard
- 最优解: 241221_4.py

## 题型
滑动窗口 · 哈希计数

## 识别信号
- 求满足条件的"最短（或最长）连续子串 / 子数组"
- 条件可以在窗口左端或右端增减一个元素时增量更新（这里是字符计数）

## 解题步骤
记 m = len(s)，n = len(t)，k = t 中不同字符的种数，w = 窗口长度。
1. 暴力：枚举 s 的所有子串，逐个检查是否覆盖 t，至少 O(m²)
2. 滑动窗口：右端扩张直到覆盖 t，再收缩左端直到不再覆盖，过程中记录最短窗口；每个字符最多进、出窗口各一次
3. 瓶颈一：每一步都重新统计整个窗口的字符（241221.py，超时）→ 字符进出窗口时增量更新计数
4. 瓶颈二：每一步都遍历 t 的所有字符种类判断是否覆盖 → 维护"还差几种字符没凑够"的计数，判断降到 O(1)
5. 细节：不要每一步都切片取子串，只在答案需要更新时切片

## 关键一步
维护 less = 还没凑够数量的字符种数：某字符的计数刚好达到需要的数量时 less 减 1，从刚好够变成不够时 less 加 1；less == 0 就说明窗口已经覆盖 t。

## 各版本
| 文件 | 思路 | 时间 | 空间 | 结论 |
| --- | --- | --- | --- | --- |
| 241221.py | 滑动窗口，每一步重新统计窗口字符 | O(m·w) | O(m + n) | 超时 |
| 241221_2.py | 字符进出时增量更新计数；每步遍历 t 的字符种类判断覆盖，每步切片 | O(m·(k + w)) | O(m + n) | 通过 |
| 241221_3.py | 再用 less 计数，覆盖判断变 O(1)；仍每步切片 | O(m·w) | O(m + n) | 通过 |
| 241221_4.py | 不再每步切片，只在答案不变长时切片 | O(m + n)，另加更新答案时的切片 | O(m + n) | 最优 |

## 易错点
- 窗口 [l, r] 的长度是 r − l + 1；241221_4.py 用 len(ans) > r − l 判断，等长窗口也会刷新答案，最短长度仍然正确
- 右端先 r += 1，确认 r < m 之后才能读 s[r]
- 左端移出字符时，要在减计数之前判断它是否"刚好够"，否则 less 会算错
