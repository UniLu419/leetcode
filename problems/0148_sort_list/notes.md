# 148. Sort List

- 链接: https://leetcode.com/problems/sort-list/
- 难度: Medium
- 最优解:

## 题型
链表 · 分治 · 快慢指针

## 识别信号
- 对链表排序，进阶要求 O(n log n) 时间、O(1) 额外空间
- 链表不能按下标随机访问，快排找基准、堆排序都不顺手；而"合并两个有序链表"（21 题）只改指针、不用额外数组

## 解题步骤
记 n = 链表节点数。
1. 暴力：把值倒进数组排序再写回链表，O(n log n) 时间、O(n) 空间；或在链表上做插入排序，O(n²)
2. 瓶颈：插入排序每插一个节点都要从头找位置；数组做法多用了 O(n) 空间
3. 自顶向下归并：快慢指针找中点并从中间断开，递归排序左右两半，再合并两个有序链表；O(n log n) 时间，递归栈 O(log n)
4. 自底向上归并：先数出 n，步长 step 取 1、2、4……，每一轮从头把链表切成长度 step 的段两两合并，用 dummy 头和 tail 指针把合并结果接回去；O(n log n) 时间、O(1) 额外空间，满足进阶

## 关键一步
归并排序天然适合链表：合并两个有序链表只改 next 指针、不需要额外数组；自底向上按步长 1、2、4…… 切段两两合并，就连递归栈也省掉了。

## 易错点
- 快慢指针找中点：fast 从 head.next 出发，否则两个节点时 slow 停在第二个，左半段永远不缩短，递归不结束
- 拆分后要把左半段尾部断开（mid.next = None），否则合并时会走进另一半
- 空链表和单节点直接返回
- 自底向上切段时，切出一段要把它的尾部断开并返回下一段的头；合并后 tail 要一直走到这一段的末尾再接下一段
- 值有重复和负数，比较用 <= 保持稳定即可
