# 74. Search a 2D Matrix

- 链接: https://leetcode.com/problems/search-a-2d-matrix/
- 难度: Medium
- 最优解:

## 题型
二分查找

## 识别信号
- 每行递增，并且每行第一个数大于上一行最后一个数——按行首尾相接就是一个整体有序的序列
- 要求 O(log(m · n))

## 解题步骤
记 m = len(matrix)，n = len(matrix[0])。
1. 暴力：逐个格子扫描，O(m·n)
2. 从右上角出发：比 target 大就左移一列，比 target 小就下移一行，每步排除一行或一列，O(m + n)
3. 两次二分：先在第一列二分找到 target 可能所在的行，再在该行内二分，O(log m + log n)
4. 一次二分：把矩阵看成长度 m·n 的有序数组，下标 i 对应 matrix[i // n][i % n]，在 [0, m·n − 1] 上二分，O(log(m·n)) 时间、O(1) 空间

## 关键一步
按行展开后整个矩阵是一个严格递增的一维数组，下标 i 映射到第 i // n 行、第 i % n 列，直接套普通二分。

## 易错点
- 下标映射用的是列数 n（每行的长度），不是行数 m
- 右端点是 m·n − 1；用 lo <= hi 写法时找不到要返回 False
- 只有一行或只有一列时也要能正确映射
- 两次二分写法里，先找"最后一个首元素 ≤ target 的行"，target 比所有数都小时没有这样的行
