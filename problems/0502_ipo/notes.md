# 502. IPO

- 链接: https://leetcode.com/problems/ipo/
- 难度: Hard
- 最优解:

## 题型
堆 · 贪心 · 排序

## 识别信号
- 最多做 k 个项目，每个项目要求当前资本 ≥ capital[i]，做完资本增加 profits[i]（利润非负），求最终最大资本
- 每一轮都要在"当前能做的项目"里挑利润最大的，而能做的项目集合随资本增长只增不减

## 解题步骤
记 n = len(profits)。
1. 暴力：做 k 轮，每轮扫描所有没做过的项目，挑 capital ≤ w 中利润最大的，O(k·n)
2. 贪心正确性：利润非负，资本只增不减；先做当前利润最大的项目，之后能解锁的项目只会更多，不会更差
3. 瓶颈：每一轮都重新扫描全部项目
4. 优化：把项目按 capital 升序排序，用指针把所有 capital ≤ w 的项目利润推进大顶堆；每轮弹出堆顶加到 w，再移动指针把新解锁的项目推进堆；堆空说明没有能做的项目，提前结束；O(n log n + k log n) 时间、O(n) 空间

## 关键一步
资本只增不减，所以"能做的项目"只会越来越多：按所需资本排序后用指针一次性加入大顶堆，每轮取堆顶利润最大的那个。

## 易错点
- 堆空时要提前退出，不能硬做满 k 轮
- 一轮资本增加后可能一下解锁多个项目，指针要用 while 一直推进
- Python 的 heapq 是小顶堆，存 −profit 模拟大顶堆
- k 可能大于 n
- 项目做完就不能重复做，排序 + 指针保证每个项目只入堆一次
