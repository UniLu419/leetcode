# 102. Binary Tree Level Order Traversal

- 链接: https://leetcode.com/problems/binary-tree-level-order-traversal/
- 难度: Medium
- 最优解:

## 题型
二叉树 · BFS

## 识别信号
- 输出是"按层分组"的二维列表，每层内从左到右
- 层序遍历的模板题，后续很多按层处理的题都基于它

## 解题步骤
记 n = 节点数，h = 树高，w = 最宽一层的节点数。
1. 暴力：对每个深度 d 从根出发 DFS 收集深度为 d 的节点，O(n·h)
2. 瓶颈：每层都重新遍历整棵树
3. 优化一：BFS 队列，每轮先取当前队列长度，正好出队这一层，同时把孩子按先左后右入队，O(n) 时间、O(w) 空间
4. 优化二：DFS 带深度参数，depth == len(ans) 时新开一层，再把节点值追加到 ans[depth]，先左后右递归，O(n) 时间、O(h) 空间

## 关键一步
用"处理这一层之前的队列长度"作为层的边界：这一轮只出队这么多个节点，它们就是同一层，期间新入队的孩子留给下一轮。

## 易错点
- 空树返回 []
- 先入队左孩子再入队右孩子，层内顺序才是从左到右
- 不要在 for 循环条件里用不断变化的 len(queue)，要先存下来（Python 的 range(len(q)) 只在开始时求一次值）
- 用 list.pop(0) 出队是 O(n)，用 collections.deque
