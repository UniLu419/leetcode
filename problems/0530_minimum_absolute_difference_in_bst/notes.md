# 530. Minimum Absolute Difference in BST

- 链接: https://leetcode.com/problems/minimum-absolute-difference-in-bst/
- 难度: Easy
- 最优解:

## 题型
二叉搜索树 · DFS

## 识别信号
- 树是二叉搜索树（BST），而问题是"任意两个节点值之差的最小值"
- BST 的中序遍历是升序序列，最小差只可能出现在升序序列的相邻两个数之间

## 解题步骤
记 n = 节点数，h = 树高。
1. 暴力：遍历收集所有值，两两比较求最小差，O(n²)
2. 瓶颈：排好序后，最小差只会出现在相邻两个数之间，大部分比较都是多余的
3. 优化一：收集所有值后排序，再比较相邻元素，O(n log n)
4. 优化二：利用 BST 的性质，中序遍历本身就按升序访问节点，边遍历边和上一个访问的值求差，O(n) 时间、O(h) 空间（递归栈或显式栈）

## 关键一步
中序遍历时维护"上一个访问的节点值" prev，每访问一个节点就用 当前值 − prev 更新答案；因为中序是升序，这个差一定是非负的相邻差。

## 易错点
- prev 的初值要能表示"还没有上一个"（None），不能用 0，节点值可以是 0
- 最小差不一定在父子之间：[236,104,701,null,227,null,911] 的最小差 9 来自 236 和它的孙节点 227
