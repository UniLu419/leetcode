# 123. Best Time to Buy and Sell Stock III

- 链接: https://leetcode.com/problems/best-time-to-buy-and-sell-stock-iii/
- 难度: Hard
- 最优解:

## 题型
动态规划 · 前后缀最大值

## 识别信号
- 买卖股票，最多完成两笔交易，且手上最多持有一股
- 每天能做什么只取决于"已经完成了几次买卖、现在手里有没有股票"

## 解题步骤
记 n = len(prices)。
1. 暴力：枚举两笔交易的四个买卖日，O(n⁴)
2. 拆分点：两笔交易一定落在某个分界日的两侧，枚举分界日，左右各求一次"最多一笔交易"（121 题），O(n²)
3. 瓶颈：每个分界日都在重新扫描左右两段
4. 前后缀：left[i] = 前 i 天内一笔交易的最大利润（从左往右维护最低价），right[i] = 第 i 天及以后一笔交易的最大利润（从右往左维护最高价），答案是 max(left[i] + right[i])，O(n) 时间、O(n) 空间
5. 状态机 DP：用四个变量 buy1、sell1、buy2、sell2 表示"第一次买入后 / 第一次卖出后 / 第二次买入后 / 第二次卖出后"的最大余额，记 p = 当天价格，每天依次更新 buy1 = max(buy1, −p)、sell1 = max(sell1, buy1 + p)、buy2 = max(buy2, sell1 − p)、sell2 = max(sell2, buy2 + p)；答案 sell2，O(n) 时间、O(1) 空间

## 关键一步
把"第几次买入、第几次卖出"做成状态：第二次买入的成本从第一次卖出后的余额里扣，这样一次遍历就同时管住两笔交易。

## 易错点
- buy1、buy2 初值是 −prices[0] 或负无穷，不能是 0（0 表示免费买到了股票）
- 同一天按 buy1 → sell1 → buy2 → sell2 的顺序原地更新没有问题：同一天买入又卖出收益为 0，不会多算
- "最多"两笔：只做一笔或不做也合法，sell2 ≥ sell1 ≥ 0 已经覆盖这两种情况
- 只有一天，或价格一直下跌时答案为 0
