# 71. Simplify Path

- 链接: https://leetcode.com/problems/simplify-path/
- 难度: Medium
- 最优解: 241223.py

## 题型
栈 · 字符串模拟

## 识别信号
- ".." 表示回到上一级，要撤销"最近一次进入的目录"，后进先出
- 路径按 "/" 分段后，每一段独立处理

## 解题步骤
记 n = len(path)。
1. 暴力：反复做字符串替换（合并 "//"、去掉 "/./"、消掉 "/目录/../"）直到不再变化，每轮扫描整个串，最坏 O(n²)
2. 瓶颈：每次替换都重新扫描整个字符串
3. 优化：按 "/" 切分后一遍扫描，用栈保存当前路径：空串和 "." 跳过，".." 弹出栈顶（栈空则忽略），其他名字入栈；最后用 "/" 连接并在前面加 "/"，O(n) 时间、O(n) 空间

## 关键一步
用栈保存目录名，".." 就弹出栈顶；在根目录时栈为空，".." 什么也不做。

| 241223.py | split("/") 后用 match 分四类处理，列表当栈，最后 "/" + "/".join(栈) | O(n) | O(n) | 最优 |

## 易错点
- 只有恰好是 "." 或 ".." 的段才特殊，"..."、"..hidden" 都是普通目录名
- 根目录再 ".." 仍是根目录：弹栈前要确认栈非空
- 连续的 "/" 和末尾的 "/" 切分后会产生空串，要跳过
- 栈为空时结果是 "/"
