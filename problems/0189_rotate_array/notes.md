# 189. Rotate Array

- 链接: https://leetcode.com/problems/rotate-array/
- 难度: Medium
- 最优解: 241211_2.py

## 题型
双指针

## 识别信号
- 数组原地向右轮转 k 步，进阶要求 O(1) 额外空间
- k 可能大于数组长度，需要先对长度取模

## 解题步骤
记 n = len(nums)，k 先取 k % n。
1. 暴力：每次把最后一个元素移到最前面，做 k 次；每次移动是 O(n)，总共 O(n·k)
2. 额外数组：把 nums[i] 放到下标 (i + k) % n，O(n) 时间但 O(n) 空间
3. 三次反转：先整体反转，再分别反转前 k 个和后 n − k 个，O(n) 时间、O(1) 空间

## 关键一步
整体反转后，原来的后 k 个元素到了前面但顺序是反的，前 k 个和后 n − k 个各自再反转一次就恢复了顺序。

| 241211_2.py | 三次反转，左右双指针交换 | O(n) | O(1) | 最优 |

## 易错点
- k 可能大于 n，必须先 k %= n
- k % n == 0 时 reverse(0, k − 1) 区间为空，while l < r 自然跳过
- 题目要求原地修改、不返回值
