# 202. Happy Number

- 链接: https://leetcode.com/problems/happy-number/
- 难度: Easy
- 最优解: 241218.py

## 题型
哈希表 · 快慢指针

## 识别信号
- 反复做同一个变换，结果要么到达 1，要么无限循环
- 判断"是否进入循环"：记录见过的值，或者用快慢指针判环

## 解题步骤
1. 模拟：反复计算各位数字的平方和，直到等于 1；难点是不等于 1 时什么时候停
2. 瓶颈：要能识别循环。一个 d 位数的各位平方和不超过 81·d，数字很快降到 243 以内，所以序列只会在有限个值里打转，要么到 1，要么进入循环
3. 哈希表：记录出现过的数，重复出现就说明进入循环，返回 False
4. 快慢指针：把序列看成链表，慢指针走一步、快指针走两步，相遇时看是不是 1，额外空间 O(1)

## 关键一步
平方和序列只能到 1 或进入循环，问题等价于判环：见过的数再次出现，就不是快乐数。

## 易错点
- 原注释：注意边界条件。n == 1 要先返回 True，否则 while current != 1 一次都不执行，函数返回 None
- 原注释：由于这道题提到了结果是1或者loop，则一定会有元素被重复计算，所以可以用hash map来存放计算结果，如果有计算过的证明进入loop
