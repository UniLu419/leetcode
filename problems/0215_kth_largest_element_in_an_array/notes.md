# 215. Kth Largest Element in an Array

- 链接: https://leetcode.com/problems/kth-largest-element-in-an-array/
- 难度: Medium
- 最优解:

## 题型
堆 · 分治

## 识别信号
- 只要第 k 大的一个元素，不需要整体有序
- 题目提示"能否不排序"：维护前 k 大用堆；只找一个位置用快速选择

## 解题步骤
记 n = len(nums)。
1. 暴力：排序后取 nums[n − k]，O(n log n)
2. 瓶颈：只要一个位置上的元素，却把所有元素都排好了
3. 优化一：小顶堆保留目前最大的 k 个数，遍历时入堆，超过 k 个就弹出堆顶，最后堆顶就是第 k 大，O(n log k) 时间、O(k) 空间
4. 优化二：快速选择——随机选一个 pivot，把数组分成大于、等于、小于 pivot 三组；根据 k 落在哪一组，只在那一组里继续找（落在等于组就直接返回 pivot），期望 O(n) 时间
5. 另一条路（利用值域 −10^4 ~ 10^4）：计数数组统计每个值出现次数，从大到小累加到 k，O(n + 值域)

## 关键一步
快速选择：分组后 pivot 的排名就确定了，第 k 大只会落在其中一组，只递归那一组，期望工作量 n + n/2 + n/4 + …… = O(n)。

## 易错点
- 是第 k 大，不是第 k 小，也不是第 k 个不同的数（重复值要计入）
- pivot 要随机选，并且等于 pivot 的元素单独成组；否则数组有序或大量重复时退化成 O(n²)
- 小顶堆的大小保持 k，堆顶是第 k 大，不是最大
- 下标换算：第 k 大 = 升序排列后下标 n − k
