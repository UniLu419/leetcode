# 19. Remove Nth Node From End of List

- 链接: https://leetcode.com/problems/remove-nth-node-from-end-of-list/
- 难度: Medium
- 最优解: 241225.py

## 题型
链表 · 快慢指针

## 识别信号
- 要删"倒数第 n 个"节点，而单链表只能从头往后走
- 进阶要求只遍历一次：让一个指针比另一个固定落后 n 步

## 解题步骤
记 L = 链表长度。
1. 两遍扫描：第一遍数出 L，第二遍走到第 L − n 个节点（待删节点的前驱），把它的 next 跳过一个，O(L)
2. 进阶要一遍：前面的指针一直往后走，后面的指针等前面的走出 n 步之后才开始跟着走
3. 前面的指针走到表尾时，后面的指针正好停在待删节点的前驱上
4. 待删的是头节点（n = L）时没有前驱，需要特判，或者在表头前加一个哑节点统一处理

## 关键一步
后面的指针始终比前面的指针落后 n 步，停在待删节点的前驱；前面的指针走完时执行 前驱.next = 前驱.next.next。

## 各版本
| 文件 | 思路 | 时间 | 空间 | 结论 |
| --- | --- | --- | --- | --- |
| 241225.py | 一遍扫描：head 往后走并计数，计数超过 n 之后 aim_parent 才从表头开始跟着走；aim_parent 为空说明删的是头节点，返回 head.next | O(L) | O(1) | 最优 |

## 易错点
- 删的是头节点（[1]，n = 1；[1,2]，n = 2）时没有前驱：241225.py 用 aim_parent 是否为空来判断，为空时返回 ans.next
- 后面的指针要停在待删节点的"前一个"，所以要落后 n 步，而不是 n − 1 步
- 删完变成空链表时返回 None
