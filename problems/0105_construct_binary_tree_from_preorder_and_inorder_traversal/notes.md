# 105. Construct Binary Tree from Preorder and Inorder Traversal

- 链接: https://leetcode.com/problems/construct-binary-tree-from-preorder-and-inorder-traversal/
- 难度: Medium
- 最优解:

## 题型
二叉树 · 分治 · 哈希表

## 识别信号
- 用两种遍历序列还原树：前序的第一个元素是根，中序里根左边是左子树、右边是右子树
- 节点值互不相同，可以用值在中序里唯一定位根

## 解题步骤
记 n = 节点数。
1. 直接递归：取 preorder[0] 为根，在 inorder 里线性查找根的位置 k，左子树大小就是 k；把两个数组切片后分别递归构建左右子树。树退化成链时每层查找和切片都是 O(n)，总 O(n²)
2. 瓶颈一：每层都线性查找根在中序中的位置 → 预先建哈希表 值 → 中序下标，查找变 O(1)
3. 瓶颈二：每层切片都在复制数组 → 改为只传下标区间（前序起点 + 中序区间 [lo, hi]），不复制
4. 最优：哈希表 + 下标区间递归（或用一个前序指针按 根 → 左 → 右 的顺序依次取根，只传中序区间），O(n) 时间、O(n) 空间

## 关键一步
前序的第一个元素是根，它在中序中的位置把中序分成左右两棵子树，左子树的节点个数决定了前序里左右子树的分界。

## 易错点
- 左子树大小 = 根在中序中的下标 − 中序区间起点；前序里左子树区间是 [前序起点 + 1, 前序起点 + 左子树大小]
- 用前序指针依次取根时，必须先建左子树再建右子树（前序是 根-左-右）
- 区间为空（lo > hi）返回 None
