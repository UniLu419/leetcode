# 392. Is Subsequence

- 链接: https://leetcode.com/problems/is-subsequence/
- 难度: Easy
- 最优解: 241211.py

## 题型
双指针

## 识别信号
- 判断 s 是否是 t 的子序列：字符相对顺序要保持，但不要求连续
- 两个序列各自单向前进、互相匹配，适合两个指针同步扫描

## 解题步骤
记 n = len(s)，m = len(t)。
1. 暴力：枚举 t 的所有子序列和 s 比较，O(2^m)
2. 关键观察：s 的当前字符匹配 t 里最早出现的位置永远不会更差（贪心），留给后面的字符空间最大
3. 双指针：i 指 s、j 指 t，t[j] == s[i] 时 i 前进，j 每步都前进，最后看 i 是否走完 s，O(n + m)

## 关键一步
贪心匹配：s 的每个字符都和 t 中能匹配的最早位置配对，配上就移动 s 的指针。

| 241211.py | 双指针贪心匹配，最后判断 i == n | O(n + m) | O(1) | 最优 |

## 易错点
- s 为空串时应返回 True；循环一次都不进，i == n == 0 正好成立
- s 比 t 长、或字符顺序不对（"ab" 和 "ba"）时返回 False
