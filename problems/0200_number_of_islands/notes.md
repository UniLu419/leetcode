# 200. Number of Islands

- 链接: https://leetcode.com/problems/number-of-islands/
- 难度: Medium
- 最优解:

## 题型
DFS · BFS · 并查集

## 识别信号
- 二维网格，上下左右相邻的 '1' 连成一块，求块（连通分量）的个数
- 典型的网格连通分量计数

## 解题步骤
记 m = 行数，n = 列数。
1. 暴力：对每个 '1' 都做一次搜索找出它所在的岛，再把岛去重计数；同一座岛被反复搜索，最坏 O((m·n)²)
2. 瓶颈：没有记录哪些格子已经属于某座数过的岛
3. 优化一：按行扫描，遇到未访问的 '1' 答案加 1，并立刻用 DFS/BFS 把整座岛标记为已访问（可直接改成 '0'），每个格子只进入一次，O(m·n) 时间，最坏 O(m·n) 空间（整张图都是陆地时的栈/队列）
4. 另一种：并查集，把相邻的 '1' 合并，初始个数为 '1' 的数量，每次成功合并减 1，O(m·n·α(m·n))

## 关键一步
扫描到一个还没访问过的 '1' 时答案加 1，并立刻把它所在的整座岛"淹掉"（全部标记为已访问），这样同一座岛的其他格子之后都会被跳过，每座岛只被数一次。

## 易错点
- 网格里是字符 '1' / '0'，不是整数 1 / 0
- 只算上下左右四个方向，对角线不相连
- 递归 DFS 在 300×300 全是 '1' 时深度可达 9×10^4，会超过 Python 默认递归上限，可改用 BFS 或显式栈
- BFS 要在入队时就标记，等出队再标记会让同一格子重复入队
