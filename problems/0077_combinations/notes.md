# 77. Combinations

- 链接: https://leetcode.com/problems/combinations/
- 难度: Medium
- 最优解:

## 题型
回溯

## 识别信号
- 返回从 1..n 中选 k 个数的所有组合 → 枚举全部方案
- 组合不计顺序 → 规定只往后选，避免同一组合以不同顺序重复出现

## 解题步骤
记 C = C(n, k) 为组合数。
1. 暴力：枚举 1..n 的全部 2^n 个子集（例如用二进制掩码），保留大小为 k 的，O(2^n·n)
2. 瓶颈：大部分子集的大小不是 k，白白生成
3. 回溯：递归时带起点 start，下一个数只从 start..n 中选，路径长度达到 k 就收集；只往后选保证每个组合只以升序生成一次，O(C·k) 加上中途失败的分支
4. 剪枝：还差 k − len(path) 个数时，下一个数最大只能取到 n − (k − len(path)) + 1，剩下的数不够凑满的分支直接不进入，搜索节点数与输出同阶

## 关键一步
下一个数只从上一个数之后开始选，并且只在剩余的数还够凑满 k 个时才继续，这样每个组合恰好按升序生成一次。

## 易错点
- 收集结果时要拷贝路径（path[:]），否则回溯会把它清空
- 剪枝上界 n − (k − len(path)) + 1 容易差一，用 k == n 的情况验证
- [1, 2] 和 [2, 1] 是同一个组合，只能出现一次
