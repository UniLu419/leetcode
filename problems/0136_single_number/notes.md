# 136. Single Number

- 链接: https://leetcode.com/problems/single-number/
- 难度: Easy
- 最优解:

## 题型
位运算

## 识别信号
- 除一个数外，其他每个数恰好出现两次
- 要求线性时间、只用常数额外空间，排除了哈希表计数

## 解题步骤
记 n = len(nums)。
1. 暴力：对每个数用 count 数出现次数，O(n²)
2. 哈希表计数，再找出现一次的数，O(n) 时间、O(n) 空间
3. 数学：2·sum(set(nums)) - sum(nums)，O(n) 时间、O(n) 空间
4. 瓶颈：题目要求 O(1) 额外空间
5. 位运算：把所有数异或起来，O(n) 时间、O(1) 空间

## 关键一步
异或满足交换律和结合律，并且 a ^ a = 0、a ^ 0 = a，所以成对出现的数全部抵消，最后剩下的就是只出现一次的数。

## 易错点
- 异或的初始值是 0
- 负数同样适用，Python 的整数异或对负数也成立
- 只有一个元素时答案就是它，异或写法天然覆盖
