# 209. Minimum Size Subarray Sum

- 链接: https://leetcode.com/problems/minimum-size-subarray-sum/
- 难度: Medium
- 最优解: 241215.py

## 题型
滑动窗口

## 识别信号
- 求和 ≥ target 的最短连续子数组
- 元素全是正数：右端扩张时和只增、左端收缩时和只减，满足滑动窗口需要的单调性

## 解题步骤
记 n = len(nums)。
1. 暴力：枚举所有起点和终点，边累加边判断，O(n²)
2. 前缀和 + 二分：前缀和单调递增，对每个起点二分找最近的终点，O(n log n)（题目的进阶要求）
3. 滑动窗口：右端扩张直到和 ≥ target，然后收缩左端并记录长度，每个元素进出窗口各一次，O(n)

## 关键一步
窗口和 ≥ target 时，固定左端继续扩右端只会更长，所以记录长度后直接把左端右移。

## 易错点
- 原注释：一定注意先减后挪，先 sum -= nums[l] 再 l += 1
- 不存在满足条件的子数组时返回 0：用 n + 1 作哨兵判断
