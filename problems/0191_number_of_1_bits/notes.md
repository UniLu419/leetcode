# 191. Number of 1 Bits

- 链接: https://leetcode.com/problems/number-of-1-bits/
- 难度: Easy
- 最优解:

## 题型
位运算

## 识别信号
- 统计一个正整数二进制表示中 1 的个数（汉明重量）
- 只关心二进制位，适合直接做位运算

## 解题步骤
记 b = n 的二进制位数（≤ 31），c = n 中 1 的个数。
1. 字符串：bin(n).count("1")，O(b)
2. 逐位：每次看最低位 n & 1，然后右移一位，直到 n 为 0，O(b)
3. 优化：每次执行 n &= n - 1 消掉最低位的 1，循环次数等于 1 的个数，O(c)

## 关键一步
n - 1 会把 n 最低位的那个 1 变成 0、它右边的 0 全变成 1，再和 n 相与，恰好只消掉这一个 1。

## 易错点
- Python 里 n 就是普通整数，不是二进制字符串，直接做位运算
- 循环条件用 while n；如果 n 可能是负数，Python 的右移永远不会得到 0 会死循环（本题 n ≥ 1，不涉及）
- 2147483647 有 31 个 1，2147483645 有 30 个 1
