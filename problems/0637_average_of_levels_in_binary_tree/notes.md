# 637. Average of Levels in Binary Tree

- 链接: https://leetcode.com/problems/average-of-levels-in-binary-tree/
- 难度: Easy
- 最优解:

## 题型
二叉树 · BFS

## 识别信号
- 要求"每一层"的统计量（平均值），需要按层把节点分组
- 输出长度等于树的层数

## 解题步骤
记 n = 节点数，h = 树高，w = 最宽一层的节点数。
1. 暴力：对每个深度 d 都从根出发 DFS 一遍，只累加深度为 d 的节点，O(n·h)
2. 瓶颈：每一层都把整棵树重新遍历一次
3. 优化一：BFS 按层处理，每层出队时累加和与个数，层结束时求平均，O(n) 时间、O(w) 空间
4. 优化二：DFS 一次，按深度维护 (和, 个数) 两个数组，最后逐层相除，O(n) 时间、O(h) 空间

## 关键一步
BFS 处理一层之前先记下 len(queue)，这一批出队的节点正好是这一层的全部节点，把它们的值加起来再除以这个个数。
