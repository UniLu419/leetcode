# 236. Lowest Common Ancestor of a Binary Tree

- 链接: https://leetcode.com/problems/lowest-common-ancestor-of-a-binary-tree/
- 难度: Medium
- 最优解:

## 题型
二叉树 · DFS

## 识别信号
- 求两个节点的最低公共祖先（LCA，同时是两者祖先的节点里最深的那个），并且是普通二叉树，没有 BST 的大小关系可用
- p、q 一定在树里且不相同，节点值唯一；一个节点可以是它自己的祖先

## 解题步骤
记 n = 节点数，h = 树高。
1. 暴力：对每个节点判断它的子树是否同时包含 p 和 q，取最深的那个；每次判断 O(n)，总 O(n²)
2. 瓶颈：同一棵子树被反复搜索
3. 优化一：DFS 分别求出根到 p、根到 q 的路径，两条路径上最后一个相同的节点就是答案，O(n) 时间、O(n) 空间；或先用哈希表记录每个节点的父节点，把 p 的祖先放进集合，再从 q 往上找第一个在集合里的节点
4. 优化二：一次后序递归，函数返回"这棵子树里找到的 p、q 或它们的 LCA"：遇到空节点、p 或 q 直接返回该节点；左右两边返回值都非空，说明 p、q 分在两侧，当前节点就是 LCA；只有一边非空就把那一边的结果往上返回。O(n) 时间、O(h) 栈空间

## 关键一步
后序递归时，如果左右子树都找到了目标，当前节点就是最低公共祖先；遇到 p 或 q 本身就直接返回，不用再往下找，因为另一个如果在它下面，答案就是它自己。

## 易错点
- p 是 q 的祖先时答案就是 p（p = 5、q = 4 → 5）
- p、q 和返回值都是树里的节点对象，要返回树里那个节点本身，不能新建一个同值的节点
- 判断"遇到 p 或 q"要比较节点本身（is），不要和整数比较
