# 15. 3Sum

- 链接: https://leetcode.com/problems/3sum/
- 难度: Medium
- 最优解: 241215.py

## 题型
排序 · 双指针

## 识别信号
- 找出所有和为 0 的三元组，且结果不能有重复的三元组：排序后相同的数挨在一起，方便去重
- 固定一个数后，剩下的就是"在有序数组里找两数之和等于目标值"，可以用左右双指针

## 解题步骤
记 n = len(nums)。
1. 暴力：三层循环枚举所有三元组，再用集合去重，O(n³)
2. 瓶颈：固定前两个数后，第三个数只是在找一个确定的值
3. 排序 + 双指针：先排序 O(n log n)；固定 nums[i]，在 i 右侧用左右指针找和为 −nums[i] 的两个数，和偏小就右移左指针，偏大就左移右指针，总体 O(n²)
4. 去重：固定的数、左指针、右指针移动时都跳过和当前值相同的元素

## 关键一步
排序后固定 nums[i]，在它右侧用左右双指针找两数之和等于 −nums[i]；三个位置都跳过相同的值，结果就不会重复。

## 易错点
- 三个位置都要去重：固定的数跳过相同值（[0,0,0,0] 只输出一次 [0,0,0]），找到一组后左右指针也都要跳过相同值
- 241215.py 在和偏小或偏大时也一次跳过所有相同值，而不是只移动一格，结果相同
- 输出中三元组的顺序、三元组内部数字的顺序都不重要
