# 50. Pow(x, n)

## 题型
分治 · 数学

## 识别信号
- 指数 n 可达 ±2^31，逐次相乘 O(n) 会超时
- x^n = (x^(n / 2))^2，问题规模可以每次减半

## 解题步骤
记 N = abs(n)。
1. 暴力：循环乘 N 次，O(N)，N 约 2·10^9 时超时
2. 瓶颈：反复计算相同的子乘积
3. 快速幂（递归）：x^N = (x^(N // 2))^2，N 为奇数时再乘一个 x，O(log N) 时间、O(log N) 递归栈
4. 快速幂（迭代）：按 N 的二进制从低位到高位，x 每轮平方依次得到 x^1、x^2、x^4、…，N 的当前位为 1 就把它乘进结果，O(log N) 时间、O(1) 空间
5. n < 0 时先算 x^N 再取倒数（或先令 x = 1 / x）

## 关键一步
把 n 写成二进制：x^n 等于 n 中为 1 的那些位对应的 x^(2^i) 的乘积，而 x^(2^i) 由上一项平方得到，只需 O(log n) 次乘法。

## 易错点
- n 为负数要取倒数；n = -2^31 时 -n 在 Java / C++ 会溢出，Python 不会
- 递归时要先算一次 half = myPow(x, N // 2) 再 half * half，写成两次递归调用会退化回 O(N)
- n = 0 返回 1.0；题目保证 x = 0 时 n > 0
- 结果是浮点数，和期望值比较允许 1e-5 的误差
