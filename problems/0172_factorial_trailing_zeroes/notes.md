# 172. Factorial Trailing Zeroes

- 链接: https://leetcode.com/problems/factorial-trailing-zeroes/
- 难度: Medium
- 最优解:

## 题型
数学

## 识别信号
- 末尾 0 的个数 = 因子 10 的个数 = min(因子 2 的个数, 因子 5 的个数)
- n! 非常大（n = 10^4 时有 3.5 万多位），不应真的算出来

## 解题步骤
1. 暴力：算出 n! 再从末尾数 0，n = 10^4 时要处理 3.5 万多位的大整数
2. 优化一：末尾 0 来自 2 × 5，因子 2 远多于因子 5，只需数 1..n 每个数含几个因子 5 再求和，O(n log n)
3. 优化二：n 以内 5 的倍数有 n // 5 个，各贡献一个 5；25 的倍数再各多贡献一个；125 的倍数再多一个……答案 = n // 5 + n // 25 + n // 125 + …，O(log n)

## 关键一步
答案 = n // 5 + n // 25 + n // 125 + …：反复执行 n //= 5 并把结果累加，直到 n 为 0。

## 易错点
- 25、125 这类数含多个因子 5，只算 n // 5 会少算（25! 末尾有 6 个 0，不是 5 个）
- 不需要数因子 2，它总是比因子 5 多
- 暴力法里 str(math.factorial(10000)) 在 Python 3.11 及以上会抛 ValueError（整数转字符串超过 4300 位的默认上限）
- n = 0 时 0! = 1，答案是 0
