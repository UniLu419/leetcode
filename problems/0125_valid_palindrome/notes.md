# 125. Valid Palindrome

- 链接: https://leetcode.com/problems/valid-palindrome/
- 难度: Easy
- 最优解: 241215.py

## 题型
双指针 · 字符串模拟

## 识别信号
- 判断回文，但要先忽略大小写、只保留字母和数字
- 回文判断天然是首尾两端向中间对比

## 解题步骤
记 n = len(s)。
1. 直接做：转小写、过滤出字母数字，再和自身反转比较，O(n) 时间、O(n) 额外空间
2. 双指针：在过滤后的序列上左右指针向中间比较，遇到不同立即返回，时间相同
3. 省空间：不建新序列，左右指针直接在原串上走，跳过非字母数字字符，比较时转小写，O(1) 额外空间

## 关键一步
左右指针各自先跳过非字母数字字符，再比较两个字符的小写形式。

## 易错点
- 数字也要保留："0P" 不是回文
- 过滤后为空（如 " "）算回文，返回 True
- 下划线等符号不是字母数字，要跳过
