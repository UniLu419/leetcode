# 208. Implement Trie (Prefix Tree)

- 链接: https://leetcode.com/problems/implement-trie-prefix-tree/
- 难度: Medium
- 最优解:

## 题型
字典树 · 设计

## 识别信号
- 需要按前缀查询（startsWith），哈希集合只能做整词匹配
- 字符集固定为 26 个小写字母，单词之间大量共享前缀

## 解题步骤
记 L = 单词或前缀的长度，W = 已插入的单词数。
1. 暴力：集合存所有单词，search O(L)；startsWith 遍历全部单词比较前缀，O(W·L)
2. 瓶颈：每次 startsWith 都要扫所有单词，公共前缀被反复比较
3. 优化一：把每个单词的所有前缀也放进集合，startsWith 变 O(L)，但每次 insert 要 O(L²) 时间和空间
4. 最优：字典树。每个节点存"下一个字符 → 子节点"的映射（dict 或长度 26 的数组）和一个"单词结尾"标记；insert、search、startsWith 都沿字符往下走 L 步，O(L)；总空间为所有插入单词的字符总数

## 关键一步
每个节点代表一个前缀，子节点按下一个字符分叉；search 和 startsWith 走的是同一条路径，区别只在最后是否要求该节点带"单词结尾"标记。

## 易错点
- search 走到最后还要检查结尾标记："app" 是 "apple" 的前缀，但不一定是插入过的单词
- 中途某个字符的子节点不存在，要立刻返回 False
- 用 dict 实现时若把结尾标记也存成一个键（如 "$"），要确保它不会和字母冲突
- 同一个单词重复插入不能出错
