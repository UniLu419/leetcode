# 2. Add Two Numbers

- 链接: https://leetcode.com/problems/add-two-numbers/
- 难度: Medium
- 最优解: 241223.py

## 题型
链表 · 数学

## 识别信号
- 两个非负整数按"逆序"存在链表里，个位在表头，正好可以从头开始逐位相加
- 返回同样格式的链表，结果最多比较长的链表多 1 位（最高位进位）

## 解题步骤
记 m、n 为两个链表的长度。
1. 直接做法：把两个链表还原成整数相加再拆回链表；链表最长 100 位，在固定宽度整数的语言里会溢出
2. 模拟竖式加法：同时遍历两条链表，每一位算 a + b + 进位，拆出当前位和新进位，O(max(m, n))
3. 一条链表走完后，另一条剩下的部分继续和进位相加
4. 两条都走完后，进位不为 0 就再补一个节点

## 关键一步
每一位的结果是 (a + b + 进位) 的个位，新进位是它整除 10；两条链表都走完后进位不为 0 还要补一个节点。

## 易错点
- 最高位产生进位时（[5] + [5] → [0,1]）要额外补一个节点
- 一条链表走完后，剩下的部分仍要带着进位继续加（[9,9,9,9,9,9,9] + [9,9,9,9]）
- 241223.py 不用哑节点，只在第一个循环里设置表头 ans；题目保证两条链表都非空，所以第一个循环至少执行一次
