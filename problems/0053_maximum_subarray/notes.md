# 53. Maximum Subarray

- 链接: https://leetcode.com/problems/maximum-subarray/
- 难度: Medium
- 最优解:

## 题型
动态规划 · 前缀和

## 识别信号
- 求和最大的非空连续子数组，只要最大和、不要求位置
- n 可达 10^5，枚举所有子数组 O(n²) 会超时；"以每个位置结尾的最优解"只和前一个位置有关

## 解题步骤
记 n = len(nums)。
1. 暴力：枚举起点和终点，边扩展终点边累加，O(n²)
2. 瓶颈：每个终点都要回头和所有起点配对
3. 前缀和：子数组和 = pre[j] − pre[i]；固定终点 j 时只需要它之前最小的前缀和，一遍扫描同时维护最小前缀，O(n) 时间、O(1) 空间
4. 动态规划：记 cur = 以 i 结尾的最大子数组和，cur = max(cur + nums[i], nums[i])，答案是所有 cur 的最大值；只依赖前一项，O(n) 时间、O(1) 空间
5. 进阶（题目要求的分治）：把区间分成左右两半，答案要么完全在左半、要么完全在右半、要么跨过中点（从中点分别向左、向右求最大延伸和再相加），O(n log n)

## 关键一步
以 i 结尾的最大子数组，要么接在以 i − 1 结尾的最优子数组后面，要么从 i 重新开始；前面累计的和是负数就丢掉。

## 易错点
- 全是负数时答案是最大的那个负数，不是 0：初值用 nums[0]，不要用 0
- 子数组必须非空
- 前缀和写法要先用 pre[j] − 最小前缀 更新答案，再把 pre[j] 计入最小前缀；最小前缀的初值是空前缀 0
