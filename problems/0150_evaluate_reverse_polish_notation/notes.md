# 150. Evaluate Reverse Polish Notation

- 链接: https://leetcode.com/problems/evaluate-reverse-polish-notation/
- 难度: Medium
- 最优解: 241223.py

## 题型
栈

## 识别信号
- 逆波兰表达式（后缀表达式）：每个运算符作用于它前面最近的两个操作数
- "最近出现的先被使用"，是后进先出的结构

## 解题步骤
记 n = len(tokens)。
1. 暴力：反复找到第一个运算符，把它和前面两个数替换成计算结果；每次替换都要移动后面的元素，O(n²)
2. 瓶颈：每次都要重新扫描、重排整个列表
3. 优化：从左到右扫一遍，数字入栈；遇到运算符就弹出两个数，计算后把结果压回栈，O(n)

## 关键一步
遇到运算符时，先弹出的是右操作数 b，后弹出的是左操作数 a，计算 a op b 后压回栈。

## 易错点
- 减法和除法不满足交换律：先弹出的是 b（右操作数），后弹出的是 a
- 除法要向零截断：Python 的 -7 // 2 = -4（向下取整），题目要 -3，int(a / b) 才对
- 负数 token（如 "-11"）不是运算符，要整体转成整数；match 精确匹配 "-" 时自然区分开
