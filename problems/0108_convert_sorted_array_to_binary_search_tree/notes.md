# 108. Convert Sorted Array to Binary Search Tree

- 链接: https://leetcode.com/problems/convert-sorted-array-to-binary-search-tree/
- 难度: Easy
- 最优解: 231118.py

## 题型
二叉树 · 递归

## 识别信号
- 输入是升序数组，要构造高度平衡的二叉搜索树
- 升序数组就是 BST 的中序遍历；"平衡"提示每次取中间元素当根

## 解题步骤
记 n = len(nums)。
1. 中间元素当根，左半段递归建左子树，右半段递归建右子树，左右节点数最多差 1，所以高度平衡
2. 每个元素建一个节点，O(n) 时间，递归深度 O(log n)
3. 用下标区间 [start, end] 递归，不要切片复制子数组

## 关键一步
取区间中点作为根：左右两段大小最多差 1，整棵树自然高度平衡，且中序仍是原数组。

## 各版本
| 文件 | 思路 | 时间 | 空间 | 结论 |
| --- | --- | --- | --- | --- |
| 231118.py | 下标区间递归取中点（偶数长度取偏右的中点），长度 1 和 2 单独处理 | O(n) | O(log n) | 最优 |

## 易错点
- 答案不唯一：偶数长度取左中点或右中点都对，[1,3] 返回 [3,1] 或 [1,null,3] 都行
- 231118.py 把长度 1、2 作为终止条件，长度 ≥ 3 时 mid − 1 和 mid + 1 两侧都非空，所以不会出现空区间；若改成用 start > end 终止，就要返回 None
