# 211. Design Add and Search Words Data Structure

- 链接: https://leetcode.com/problems/design-add-and-search-words-data-structure/
- 难度: Medium
- 最优解:

## 题型
字典树 · DFS · 设计

## 识别信号
- 查询中的 "." 能匹配任意一个字母 → 遇到它要在多个分支里尝试
- 单词逐字符匹配、大量共享前缀 → 字典树

## 解题步骤
记 W = 已添加的单词数，L = 单词长度（≤ 25），每个查询最多 2 个 "."。
1. 暴力：列表存所有单词，search 时逐个比较长度和每一位（"." 跳过比较），每次查询 O(W·L)
2. 瓶颈：每次查询都要扫所有单词，公共前缀被反复比较
3. 优化一：按长度分组，只和等长的单词比较，常数变小，最坏仍是 O(W·L)
4. 最优：字典树。addWord 插入 O(L)；search 在树上 DFS，普通字母只走对应的唯一子节点，遇到 "." 就遍历当前节点的所有子节点；不含 "." 时 O(L)，含 2 个 "." 时最坏约 O(26²·L)

## 关键一步
遇到 "." 时，对当前节点的每一个子节点递归匹配剩下的部分，任何一条分支成功就返回 True。

## 易错点
- 匹配完所有字符后还要检查结尾标记，长度不同不算匹配
- "." 要试遍所有子节点：只有遇到成功才能提前返回，不能直接返回第一个分支的结果
- 用 "$" 之类的键做结尾标记时，遍历子节点要跳过它
- 空字典上的查询返回 False
