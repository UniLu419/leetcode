# 120. Triangle

- 链接: https://leetcode.com/problems/triangle/
- 难度: Medium
- 最优解:

## 题型
动态规划

## 识别信号
- 从顶到底一步只能走到下一行相邻的两个位置，求路径和的最小值
- 同一个位置可以从上一行两个位置到达，不同路径会经过相同的格子（重叠子问题）

## 解题步骤
记 n = 三角形的行数，元素总数约 n²/2。
1. 暴力：递归枚举每条从顶到底的路径，共 2^(n−1) 条，O(2^n)
2. 瓶颈：从同一个位置 (i, j) 往下走的最小路径和被很多条路径重复计算
3. 自顶向下 DP：dp[i][j] = triangle[i][j] + min(dp[i−1][j−1], dp[i−1][j])，每行首尾只有一个来源要单独处理；答案是最后一行的最小值，O(n²) 时间、O(n²) 空间
4. 自底向上 DP：从倒数第二行往上算，dp[j] = triangle[i][j] + min(dp[j], dp[j+1])，最后 dp[0] 即答案；没有边界特判，O(n²) 时间、O(n) 空间

## 关键一步
从底往上算：每个位置下方都恰好有两个相邻位置可选，没有边界情况，最后所有路径汇聚到顶点 dp[0]。

## 易错点
- 自顶向下时每行第一个和最后一个元素只有一个父节点，下标会越界
- 一维数组的更新方向：自底向上时 j 从小到大（dp[j+1] 还是下一行的旧值）；自顶向下时 j 必须从大到小
- 不能每步贪心选下一行较小的那个：可能错过更深处很小的数（元素还可能是负数）
- 只有一行时答案就是那个元素
