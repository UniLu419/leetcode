# 167. Two Sum II - Input Array Is Sorted

- 链接: https://leetcode.com/problems/two-sum-ii-input-array-is-sorted/
- 难度: Medium
- 最优解: 241215_2.py

## 题型
双指针

## 识别信号
- 数组已按非递减顺序排好，找两个数之和等于 target
- 要求只用常数额外空间，提示不用哈希表、改用有序性

## 解题步骤
记 n = len(numbers)。
1. 暴力：两层循环枚举所有数对，O(n²)
2. 哈希表：像 1. Two Sum 一样存"值 → 下标"，O(n) 时间但 O(n) 空间，没用上"有序"
3. 双指针：l 从左、r 从右；和偏小就右移 l，和偏大就左移 r，相等即为答案，O(n) 时间、O(1) 空间

## 关键一步
和小于 target 时，numbers[l] 与剩下任何一个数相加都不会超过当前的和，所以 l 可以直接排除；和大于 target 时同理排除 r。

## 各版本
| 文件 | 思路 | 时间 | 空间 | 结论 |
| --- | --- | --- | --- | --- |
| 241215.py | 哈希表存"值 → 全部下标（从 1 起）"，再遍历查补数 | O(n) | O(n) | 通过，空间未达最优 |
| 241215_2.py | 左右双指针，移动时一次跳过所有相同的值 | O(n) | O(1) | 最优 |

## 易错点
- 返回的下标从 1 开始，要 +1
- 补数等于自身（[0,0,3,4]，target = 0）时要取两个不同下标：241215.py 用 index != ans[0] 跳过自己
- 原注释：由于是非降list且需要返回具体index，所以双指针比hash快
