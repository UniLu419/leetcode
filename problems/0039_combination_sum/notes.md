# 39. Combination Sum

- 链接: https://leetcode.com/problems/combination-sum/
- 难度: Medium
- 最优解:

## 题型
回溯

## 识别信号
- 返回所有和为 target 的组合，同一个数可以无限次使用 → 枚举全部方案
- 组合不计顺序（[2, 2, 3] 和 [2, 3, 2] 是同一个）→ 需要规定选择顺序来去重

## 解题步骤
记 n = len(candidates)，T = target，m = min(candidates)，递归深度最多 T / m。
1. 暴力：每一层都从全部候选里任选一个，和达到或超过 T 时停止，最后把每个结果排序后去重；同一组合的所有排列都会被生成，指数级且重复极多
2. 瓶颈：重复来自"同一组合的不同顺序"
3. 回溯 + 起点下标：递归时下一个数只能从当前下标 i 开始往后选（可以再选 i 本身，因为允许重复），每个组合只以下标非降序生成一次；搜索规模最坏约 O(n^(T/m))
4. 剪枝：先把 candidates 排序，当前候选已经大于剩余的和时，后面的更大，直接 break

## 关键一步
递归时下一个数从当前数的下标开始选（包含它自己）：既允许重复使用同一个数，又保证每个组合只生成一次。

## 易错点
- 递归传 i 而不是 i + 1（可以重复选同一个数）；传 i + 1 就变成每个数只能用一次
- 剩余和为 0 时收集；小于 0 或没有候选可选时返回
- 只有排序后才能用 break 剪枝，不排序只能 continue
- 收集结果时拷贝路径
