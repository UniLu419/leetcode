# 137. Single Number II

- 链接: https://leetcode.com/problems/single-number-ii/
- 难度: Medium
- 最优解:

## 题型
位运算

## 识别信号
- 除一个数外，其他每个数恰好出现三次
- 要求线性时间、常数额外空间；异或只能抵消成对的数，这里需要"三次抵消"

## 解题步骤
记 n = len(nums)。
1. 哈希表计数，O(n) 时间、O(n) 空间
2. 数学：(3·sum(set(nums)) - sum(nums)) // 2，O(n) 时间、O(n) 空间
3. 按位统计：对 32 个二进制位分别数所有数在这一位上 1 的个数，对 3 取余，余数就是答案在这一位上的值，O(32·n) 时间、O(1) 空间
4. 优化：用两个变量 ones、twos 作为每一位上"出现次数 mod 3"的状态（0 → 1 → 2 → 0），一次遍历同时处理所有位，O(n) 时间、O(1) 空间

## 关键一步
对每个二进制位把 1 的出现次数对 3 取余：出现三次的数在每一位上贡献 0 次或 3 次，取余后只剩下只出现一次的那个数的位。

## 易错点
- 数值可以是负数（最小 -2^31）；Python 整数没有 32 位上限，按位统计拼出答案时，第 31 位为 1 要减去 2^32 转回负数
- ones / twos 写法的更新顺序：先 ones = (ones ^ x) & ~twos，再用新的 ones 算 twos = (twos ^ x) & ~ones
- 136 的整体异或在这里不适用，出现三次的数异或后不会抵消
