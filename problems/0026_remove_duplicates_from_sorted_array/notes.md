# 26. Remove Duplicates from Sorted Array

- 链接: https://leetcode.com/problems/remove-duplicates-from-sorted-array/
- 难度: Easy
- 最优解: 231107_2.py

## 题型
双指针

## 识别信号
- 数组已经按非递减排序，要求原地去重
- 返回保留下来的个数 k，只检查前 k 个元素；要求 O(1) 额外空间

## 解题步骤
记 n = len(nums)。
1. 暴力：遇到和前一个相同的元素就 del 掉，每次删除都要把后面的元素整体前移，最坏 O(n²)
2. 瓶颈：删除带来的搬移
3. 优化：不删除只覆盖。慢指针 k 指向已保留部分的最后一个位置，快指针 i 向后扫描；nums[i] 比 nums[k] 大就写到 k + 1，O(n)

## 关键一步
数组有序，所以新出现的值一定比已保留部分的最后一个值大，只需比较 nums[i] 和 nums[k]。

## 易错点
- 慢指针 k 是下标，返回的个数是 k + 1
- 边删边遍历时不能用固定长度的 for range，231107.py 用 while 每次重新读 len(nums)
- 删除后下标不前进，否则会跳过连续的第三个重复值
