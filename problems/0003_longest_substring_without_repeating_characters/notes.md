# 3. Longest Substring Without Repeating Characters

- 链接: https://leetcode.com/problems/longest-substring-without-repeating-characters/
- 难度: Medium
- 最优解: 241215.py

## 题型
滑动窗口 · 哈希表

## 识别信号
- 求满足条件（无重复字符）的"最长连续子串"
- 右端加入一个字符时，只需看这个字符是否已经在窗口里，可以 O(1) 判断

## 解题步骤
记 n = len(s)，Σ = 字符集大小。
1. 暴力：枚举所有子串并逐个检查是否有重复，O(n³)；固定左端、边扩展边用集合判重可降到 O(n²)
2. 瓶颈：左端每次只前进一格，同一段字符被反复检查
3. 滑动窗口：右端逐个加入字符；一旦和窗口内的字符重复，左端直接跳到"该字符上次出现位置 + 1"
4. 用哈希表（或长度为字符集大小的数组）记录每个字符最后出现的下标，每个字符 O(1) 处理，总体 O(n)

## 关键一步
哈希表记录每个字符最后出现的下标；遇到重复字符时，只有它上次出现的位置还在窗口内（≥ l）才把左端移到该位置 + 1，左端只往右走。

## 易错点
- 重复字符的上次位置可能已经在窗口左边（"abba" 处理第二个 a 时），这时不能移动左端；原注释："和之前239求固定长度子序列最大值那道题一样，需要注意下标是否在窗口内"
- 空串返回 0；空格也是字符，" " 返回 1
