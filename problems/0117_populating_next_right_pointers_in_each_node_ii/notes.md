# 117. Populating Next Right Pointers in Each Node II

- 链接: https://leetcode.com/problems/populating-next-right-pointers-in-each-node-ii/
- 难度: Medium
- 最优解:

## 题型
二叉树 · BFS · 链表

## 识别信号
- 要把同一层的节点从左到右串起来，是按层处理
- 不是完美二叉树，有的节点缺孩子，下一层相邻的两个节点可能来自不相邻的父节点
- 进阶要求只用常数额外空间（递归栈不算）

## 解题步骤
记 n = 节点数，w = 最大层宽。
1. BFS：队列按层遍历，每层内把前一个节点的 next 指向当前节点，O(n) 时间、O(w) 空间
2. 瓶颈：队列要 O(w) 额外空间
3. 优化：上一层的 next 已经连好，就是一条链表；沿着它从左到右走，同时用一个哑节点加尾指针，把遇到的孩子依次接成下一层的链表；一层走完后从哑节点的 next 开始处理下一层。O(n) 时间、O(1) 空间

## 关键一步
第 i 层连好之后就是一条链表，沿着它走就能按从左到右的顺序拿到第 i + 1 层的全部孩子，用哑节点把这些孩子串起来，就连好了第 i + 1 层。

## 易错点
- 不能只在同一个父节点的左右孩子之间连：某个节点没有孩子时要沿 next 继续往右找（[1, 2, 3, 4, 5, None, 6, 7, None, None, None, None, 8] 里 7 要连到 8，中间的 5 没有孩子）
- 每一层开始前都要换一个新哑节点（或把哑节点的 next 置空），否则最后一层之后哑节点还指向上一层，循环停不下来
- 每层最后一个节点的 next 保持 None
- 空树直接返回 None
