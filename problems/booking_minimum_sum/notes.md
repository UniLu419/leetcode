## 题型
堆 · 贪心

## 识别信号
- 题目（HackerRank，Booking 面试题）：给定整数数组 num 和整数 k，执行恰好 k 次操作，每次选一个元素 x 替换成 ceil(x / 2)，返回 k 次操作后数组之和的最小可能值
- 每次都要取"当前最大值"并把变小的值放回去，是典型的最大堆场景

## 解题步骤
记 n = len(num)。
1. 贪心：每次减半当前最大的数，减少量 x − ceil(x / 2) 最大，所以每步都选最大值不会更差
2. 暴力：每次线性扫描找最大值，O(k·n)
3. 用有序数组：降序排序后每次取第一个、减半后二分找位置插回，但数组的删除和插入都要移动元素，仍是 O(n log n + k·n)
4. 最大堆：取最大、放回都是 O(log n)，总体 O(n + k log n)

## 关键一步
每次操作都作用在当前最大值上，用最大堆维护"当前最大"。

## 易错点
- 向上取整：ceil(x / 2)，不是 x / 2 向下取整
- 有序数组里先把最大值取出（shift）再插回减半值；241210.js 原地改 num[0] 后又 splice 插入，同一个值出现了两次
- 降序数组里的二分插入：遇到 num[mid] < value 往左收，否则往右，最后在 left 处插入
