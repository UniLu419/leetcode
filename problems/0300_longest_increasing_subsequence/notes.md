# 300. Longest Increasing Subsequence

- 链接: https://leetcode.com/problems/longest-increasing-subsequence/
- 难度: Medium
- 最优解:

## 题型
动态规划 · 二分查找 · 贪心

## 识别信号
- 求"子序列"（可以不连续、保持原顺序）的最长长度，条件是严格递增
- 以某个元素结尾的最优结果，只依赖它前面比它小的元素的结果

## 解题步骤
记 n = len(nums)。
1. 暴力：枚举全部 2^n 个子序列逐个检查是否递增，O(2^n · n)
2. 瓶颈：很多子序列共享同一个结尾，"以 nums[i] 结尾的最长长度"被反复计算
3. 动态规划：dp[i] = 以 nums[i] 结尾的最长递增子序列长度 = 1 + max(dp[j])，其中 j < i 且 nums[j] < nums[i]；答案是 max(dp)，O(n²) 时间、O(n) 空间
4. 瓶颈：每个 i 都要回头扫一遍所有 j
5. 优化：维护 tails，tails[L] = 长度为 L + 1 的递增子序列中最小的结尾值；tails 严格递增，对每个 x 二分找第一个 ≥ x 的位置替换，找不到就追加到末尾；答案是 len(tails)，O(n log n) 时间、O(n) 空间

## 关键一步
长度相同的递增子序列，结尾越小越容易被后面的数接上，所以每个长度只记最小的结尾；这个数组天然递增，新数字用二分找到它该替换的位置。

## 易错点
- 严格递增：要找第一个 ≥ x 的位置（bisect_left）；用 bisect_right 会让相等的数也接在后面，全相等时答案错成 n
- tails 本身不一定是一个真实存在的子序列，只有它的长度是答案
- dp 写法的答案是 max(dp)，不是 dp[-1]
- 只有一个元素、或所有元素相等时答案是 1
