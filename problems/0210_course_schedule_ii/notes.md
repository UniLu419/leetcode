# 210. Course Schedule II

- 链接: https://leetcode.com/problems/course-schedule-ii/
- 难度: Medium
- 最优解:

## 题型
图 · 拓扑排序

## 识别信号
- 先修关系构成有向图，要输出一个满足所有先修关系的上课顺序
- 有环时不存在合法顺序；合法顺序不唯一，返回任意一个即可

## 解题步骤
记 V = numCourses，E = len(prerequisites)。
1. 暴力：反复扫描所有课程，找一门先修课都已完成的课加入顺序，直到找不到为止，最坏 O(V·(V + E))
2. 瓶颈：每轮都从头扫描所有课程和边
3. 优化一（BFS 拓扑排序）：建邻接表和入度数组，入度为 0 的课入队；出队的顺序就是答案，每出队一门课把它所有后继的入度减 1，减到 0 入队；最后答案长度小于 V 说明有环，返回 []，O(V + E)
4. 优化二（DFS 后序）：三色标记 DFS，一个节点的所有后继都处理完后把它加入列表，最后把列表反转；遇到"访问中"的节点说明有环，O(V + E)

## 关键一步
每次只上入度为 0 的课（它的先修课都已经上完），上完后更新后继的入度；入度为 0 的课被取出的顺序本身就是一个合法的上课顺序。

## 易错点
- [a, b] 表示先修 b 才能修 a，边的方向是 b → a
- 有环时返回空列表 []，而不是返回已经排出的一部分
- 合法顺序不唯一，返回任意一个合法顺序都正确
- DFS 后序得到的是"后修的在前"，需要反转（或者建反向边）
- 没有先修关系的课程也必须出现在答案里
