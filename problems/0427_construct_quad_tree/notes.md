# 427. Construct Quad Tree

- 链接: https://leetcode.com/problems/construct-quad-tree/
- 难度: Medium
- 最优解:

## 题型
分治 · 递归

## 识别信号
- 网格边长 n 是 2 的幂，规则是"整块值相同就是叶子，否则四等分继续"——递归分治的结构直接写在题面里
- 节点有四个孩子，分别对应左上、右上、左下、右下四个象限

## 解题步骤
记 n = len(grid)。
1. 直接递归：对当前子方块扫描一遍判断是否全相同，相同就建叶子，否则四等分递归；每层总共扫描 n² 个格子，共 log n 层，O(n² log n)
2. 瓶颈：同一个格子在每一层都被重新扫描一次
3. 优化一：预处理二维前缀和，O(1) 求出子方块的和，和为 0 或等于边长² 就是全相同；建前缀和 O(n²)，节点数 O(n²)，总 O(n²)
4. 优化二：先递归建好四个孩子，再看四个孩子是否都是叶子且 val 相同，是就合并成一个叶子，否则当前节点为内部节点挂上四个孩子；每个格子只在 1×1 时看一次，O(n²) 时间，递归深度 O(log n)

## 关键一步
自底向上合并：先建四个孩子，若四个都是叶子且值相同，当前块就是一个叶子；这样判断"整块相同"不需要再扫描格子。

## 易错点
- 四个孩子的顺序是 topLeft、topRight、bottomLeft、bottomRight；以 (r, c) 为左上角、半边长 h 时，topRight 是 (r, c + h)，bottomLeft 是 (r + h, c)
- 合并条件是四个孩子都是叶子并且 val 相同；只比 val 不看 isLeaf，会把内部节点误合并
- 叶子节点的四个孩子必须都是 None；内部节点的 val 取 True 或 False 都算对
- 递归出口是边长为 1
