# 106. Construct Binary Tree from Inorder and Postorder Traversal

- 链接: https://leetcode.com/problems/construct-binary-tree-from-inorder-and-postorder-traversal/
- 难度: Medium
- 最优解:

## 题型
二叉树 · 分治 · 哈希表

## 识别信号
- 用两种遍历序列还原树：后序的最后一个元素是根，中序里根左边是左子树、右边是右子树
- 节点值互不相同，可以用值在中序里唯一定位根

## 解题步骤
记 n = 节点数。
1. 直接递归：取 postorder 的最后一个元素为根，在 inorder 里线性查找根的位置 k，左子树大小就是 k；把两个数组切片后分别递归构建左右子树。树退化成链时每层查找和切片都是 O(n)，总 O(n²)
2. 瓶颈一：每层都线性查找根在中序中的位置 → 预先建哈希表 值 → 中序下标，查找变 O(1)
3. 瓶颈二：每层切片都在复制数组 → 改为只传下标区间，不复制
4. 最优：哈希表 + 下标区间递归（或用一个从后序末尾往前走的指针依次取根，只传中序区间），O(n) 时间、O(n) 空间

## 关键一步
后序的最后一个元素是根，它在中序中的位置把中序分成左右两棵子树；从后序末尾往前取，依次得到的是 根 → 右子树 → 左子树 的根。

## 易错点
- 从后序末尾往前取根时，必须先建右子树再建左子树
- 左子树大小 = 根在中序中的下标 − 中序区间起点；后序里左子树区间是 [后序起点, 后序起点 + 左子树大小 − 1]，右子树紧随其后、到根之前为止
- 区间为空（lo > hi）返回 None
